# 足球場邊記錄器 v4.60

## 本版修正：本場球員名單

### 原因確認
v4.59 曾把快捷背號改成「只能加入、不能再點取消」，並且為了降低 modal 內重繪，移除了部分 `render()`。
這改變了原本已經穩定的名單操作方式，會造成：
- 已選背號無法直接再點一次取消，看起來像背號只被放到下方「已選本場名單」。
- 清空 / 移除後，modal 與首頁人數的同步時機不同，iPhone Safari 上可能出現「像是沒反應」或畫面未立即同步的感覺。

### v4.60 修正
- 快捷背號恢復：
  - 未選 → 點一下加入。
  - 已選 → 再點一下直接移除。
- 移除 v4.59 對已選快捷背號的 `pointer-events:none`。
- 移除已選快捷背號右上角的 ✓，維持原本綠色選取狀態即可。
- 清空名單後立即同步：
  - 名單 modal
  - 首頁名單人數
  - 進球 / 牌卡 / 守門員等背號來源
- 移除單一球員後也立即同步首頁。
- `render()` 後強制維持名單 modal 開啟，降低 iPhone Safari 視覺不同步問題。
- 黃牌 / 紅牌仍維持 v4.59 的中性深色玻璃底設計。
