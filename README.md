# 足球場邊記錄器 v3.21

## 本版調整：精彩防守改為「防守」

首頁第四顆高頻事件由：

- `🛡️ 精彩防守`

調整為：

- `🛡️ 防守`

使四顆主事件在視覺與語意上更一致：

- ⚽ 進球
- 🧤 撲救
- 🥅 射門
- 🛡️ 防守

## 防守新增球員背號

按下「🛡️ 防守」後會進入球員背號選擇：

- 可直接選我方常用背號
- 可輸入其他 `1～99`
- 球員背號為選填
- 若為團隊防守，可直接略過背號
- 有指定背號時，紀錄會顯示例如：`防守・忠義 #17`
- 未指定背號時，仍可正常記錄為團隊防守事件

## 歷史資料相容性

為避免誤改舊資料：

- 舊 `GREAT_PLAY` 繼續顯示「精彩配合」
- 舊 `GREAT_DEFENSE` 繼續顯示「精彩防守」
- 新版開始按首頁「防守」才會記錄為新的 `DEFENSE / 防守`

事件紀錄、摘要、PNG、HTML 報告與 CSV 都會依事件類型顯示正確名稱與球員背號。

其他既有功能維持不變。
