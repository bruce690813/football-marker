# 足球場邊記錄器 v3.20

## 本版調整：精彩配合改為精彩防守

首頁第四顆高頻事件按鈕由：

- `🙌 精彩配合`

改為：

- `🛡️ 精彩防守`

### 設計與資料相容性
- 新增事件類型 `GREAT_DEFENSE`。
- 新版開始按「精彩防守」會記錄為獨立的防守亮點事件。
- 舊版已存在的 `GREAT_PLAY / 精彩配合` 紀錄不會被改名，避免歷史資料被誤判為防守事件。
- 編輯既有事件時仍可看到「精彩配合」，也可改成「精彩防守」。
- 精彩防守維持一鍵標記，不要求輸入球員背號，與原本精彩配合的快速操作邏輯一致。
- 摘要、PNG、HTML 報告、CSV 與事件紀錄會自動顯示 `🛡️ 精彩防守`。

其他進球、助攻、撲救、射門、守門員、牌卡、延長賽與 PK 功能維持不變。
