# 足球場邊記錄器 v3.99

## 「這是什麼？」介紹視窗可讀性提升

本版只調整產品介紹 Modal，不改動主要比賽操作介面。

### 三張功能卡
卡片標題放大至約 20px：
- 🎬 一鍵標記重點
- 📊 自動整理摘要
- ⏱ 保留完整時間軸

卡片說明文字放大至約 16px，並增加行距，讓手機上更容易閱讀。

### 上方產品說明
長說明文字同步微幅放大，行距提高至約 1.55。

### 卡片間距
只增加少量上下 padding，不刻意放大整個 modal，
避免三張卡與「開始使用這個工具」按鈕被推得太下面。

### 開始使用按鈕
維持目前尺寸與視覺權重，不再額外放大。

其他功能維持 v3.98。
