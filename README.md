# 足球場邊記錄器 v3.84

## 本版調整

### 1. GK 全面改為「守門員」
所有使用者看得到的 GK 字樣統一改成中文：

- 賽前：`🧤 守門員 未設定` / `🧤 守門員 #21`
- 比賽中：`🧤 守門員 未設定` / `🧤 守門員 #21`
- 中場：同樣使用「守門員」
- 等待延長賽：同樣使用「守門員」
- 延長賽：同樣使用「守門員」
- 賽後提示文字：同樣改成「守門員」

程式內部 keeper / goalkeeper 變數與函式名稱不更動，
只統一使用者介面的顯示文字，降低功能回歸風險。

### 2. 重新設定不再獨占一列
原本賽前單獨一整列的：

`↺ 重新設定`

移除。

改成賽前狀態列右側的小型：

`↻ 重設`

只有賽前已有實際設定內容時才顯示。

### 3. 時間紀錄戶外可讀性
針對足球場大太陽與逆光環境：

- `時間紀錄` 標題放大、加粗、提高亮度
- `開始時間 / 結束時間` 放大並提高亮度
- 實際時間數字放大為高亮白色
- 展開按鈕同步加大
- 展開後的開始 / 結束 / 實際比賽時間同步強化
- 使用 tabular numbers 等寬數字，避免時間跳動造成左右位移

### 4. 狀態邏輯不變
- 賽前：名單 / 守門員可設定
- 比賽中：精簡快捷列
- 中場：可確認 / 調整
- 等待延長賽：可確認 / 調整
- PK：沿用名單選背號流程
- 全場：名單 / 守門員快捷列仍隱藏
- 全場後：`＋ 新比賽` 保留

其他功能維持 v3.83。
