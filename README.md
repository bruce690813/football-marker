# 足球場邊記錄器 v3.97

## 修正 v3.96 中場仍顯示開始 / 結束時間

### 原因
v3.96 用：

`!state.started`

判斷是否為賽前。

但中場等待下半場時，`state.started` 也可能是 false，
因此程式誤把中場判定成賽前，
讓「開始時間 / 結束時間」重新顯示。

### v3.97 修正
賽前改成完整條件判斷：

- 尚未開始
- 尚未結束
- 不在等待下一階段
- 沒有 startEpoch
- 沒有任何 period 紀錄

只有真正賽前才顯示收合的開始 / 結束時間。

### 中場
收合狀態只顯示：

`⏱ 時間紀錄    展開`

不再顯示：
- 開始時間
- 結束時間

### 等待延長賽
同樣只保留：
- 時間紀錄
- 展開

### 全場
仍保留：
- 開始時間
- 結束時間
- 展開後的實際比賽時間

另外加入狀態 CSS 保護，
確保中場 / 等待延長賽即使 started 狀態改變，
也不會再次顯示 compact 開始 / 結束時間。

其他功能維持 v3.96。
