# 足球場邊記錄器 v5.56

手機場邊即時記錄足球比賽事件的單頁工具。

目前版本：**v5.56**

## v5.56 寫實角球白漆構圖

- 角球區維持正確足球場結構：兩條邊界線形成 90° 角，並配置於場內的四分之一圓弧，不以 V 字形替代。
- 角球標線改為三層內嵌 SVG：低透明寬底漆、草灰白主漆及不規則斷續顆粒線，模擬白漆附著草葉的質感。
- 圓弧由前版 67 單位擴大至 78 單位，提升角球區辨識度；標線仍維持低彩度，不會搶過理念文字。
- 重新對準角球線與既有足球的位置，使足球落在圓弧內側並覆蓋部分白線，搭配既有接地陰影及前景草葉形成壓線感。
- 足球尺寸、足球鞋釘足跡、理念文字、三張功能卡、快速指南與主要按鈕均維持 v5.55 配置。
- 球場背景、足球、鞋釘足跡與角球標線全部直接內嵌 `index.html`，不需要額外照片或 `assets` 資料夾。
- 比分、計時、事件、PK、摘要、LocalStorage 與匯出資料格式均未變更。

## v5.55 足球鞋釘足跡與足球接地微調

- 移除 v5.54 草地上容易被看成模糊污點的兩枚一般足跡，改為一組可辨識鞋底輪廓與鞋釘的足球鞋足跡。
- 足跡整體約放大 25%，取消模糊與螢幕混色效果，採草灰色、約 35% 透明度，在低調之餘仍看得出鞋釘細節。
- 兩枚鞋印依理念文字通往右下角足球的方向排列，形成清楚但不搶文案的視線動線。
- 足球相較前版下移 3px、左移 2px，並加高、加密前景草葉遮覆，使球體更像實際壓在草皮上。
- 其餘標題、三張功能卡、文案位置、快速指南與主要按鈕均維持 v5.54 配置。
- 足球場背景、寫實足球與鞋釘足跡全部直接內嵌 `index.html`，不需要額外圖片或 `assets` 資料夾。
- 比分、計時、事件、PK、摘要、LocalStorage 與匯出資料格式均未變更。

## v5.05 全場「＋ 新比賽」Safari 遮擋根因修正

### 這次確認到真正原因
前幾版一直增加 `fullTimeBottomSpacer`，但實際上：

```css
.finalToolsCard {
  position: fixed;
}
```

而 `＋ 新比賽` 位於 `.finalToolsCard` 裡面。

因此即使按鈕後面增加 200～300px 的 spacer，
**fixed 工具卡仍固定貼著 Safari viewport 底部**，
spacer 根本無法把按鈕往上推。

這就是 v5.04 加大安全空間後仍然被擋住的原因。

### v5.05 修正方式
本版改為：

- 全場 `.finalToolsCard` 強制改成 `position: relative`
- 移除 `left:50%`
- 移除 `bottom`
- 移除 `translateX`
- 寬度改回正常 `100%`
- `＋ 新比賽` 同樣保持正常文件流
- spacer 放在工具卡之後，現在會真正產生可捲的安全尾端

流程變成：

`事件統計`
→ `事件紀錄`
→ `摘要 / 儲存圖片 / 匯出 CSV`
→ `＋ 新比賽`
→ `Safari 安全空間`

Safari 底部工具列會蓋在最後的安全空間，而不是蓋在「＋ 新比賽」上。

### 設計原則
- 不把全場畫面整體往上推
- 不用 fixed 新比賽按鈕
- 不用 sticky
- 不用 transform 抬高
- 不自動 scrollIntoView
- 使用者正常滑到底即可完整看到按鈕

## v5.25 緊急修正：HTML/CSS 結構與標題足球場

### v5.24 問題原因
上一版的測試只涵蓋 JavaScript syntax 與關鍵字 regression，沒有檢查 HTML raw-text 結構，也沒有做實際瀏覽器畫面驗證。
此外，CSS 註解中誤放了 HTML 的 style closing tag 字樣；瀏覽器會在 style raw-text 中直接把它視為真正結束標籤，即使它位於 CSS 註解內。結果後續 CSS 被當成頁面文字顯示，並且 v5.24 新增的 Header 定位規則沒有生效，因此造成 Header 換行與整體 UI 變形。

### v5.25 修正
- 以 v5.20 穩定版本重新建構，而不是沿用已破壞的 v5.24 HTML。
- 將所有散落在外層 html 結束後的 style 區塊整併回 head。
- 外層 html 結束後不再允許任何 CSS 或文字。
- 標題足球場只使用一個 canonical renderer。
- 中圈使用 CSS pixel 正圓。
- 左右每側只畫一個大禁區與一個小禁區，沒有額外球門框或重複水平線。
