# 足球場邊記錄器 v3.91

## 時間資訊分層整理

### 主畫面
比賽進行中：
`LIVE / 比賽中 / 經過時間`

中場：
`中場 / 已休息時間`

主畫面不另外加入中場開始與結束時間，
避免影響場邊快速判讀。

### 時間紀錄展開
移除與上方狀態列重複的：

`實際比賽時間`

展開後保留：
- 比賽開始
- 比賽結束
- 規定時間

若有中場紀錄，再顯示：
- 中場開始
- 中場結束
- 中場休息

中場尚未結束時：
- 中場結束顯示 `--`
- 中場休息時間持續更新

### 賽後摘要
摘要同步記錄：
- 中場開始
- 中場結束
- 中場休息

儲存圖片中的中場紀錄也同步補齊。

### 資料
本版只是重新分配顯示位置，
不刪除任何比賽時間資料。

其他功能維持 v3.90。
