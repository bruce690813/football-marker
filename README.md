# 足球場邊記錄器 v6.146

## 版本基底
以 `football_marker_v6_145.zip` 為直接修改基底；正式 v6.51 為原始設計與功能基準，v6.52、v6.53 不使用。

## 本版變更
- 只調整「視覺精簡版」PNG 的下方球場：新增有厚度的 3D 透視草皮模型、左右側面及前緣陰影。
- 使用可重複計算的場地投影，繪製中線、中圈、禁區、球門區、十二碼點與條紋。
- 移除原本平面大梯形與大足球遮蔽場線的繪法。
- 比分、現有四項統計、MVP、球衣顏色，沿用既有邏輯。
- 詳細版、摘要、雙圖片分享、CSV、手機畫面及比賽程序未作調整。

## 使用方式
開啟 `index.html`，於完成的比賽進入摘要，按「分享/儲存圖片」同時分享詳細版及視覺精簡版。

## 限制
球場為 Canvas 原生透視 3D 風格插畫，而非真正 3D 模型或寫實影像；遇到大量事件時，仍須驗證 iPhone Safari 的記憶體與分享相容性。
