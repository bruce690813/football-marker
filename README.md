# 足球場邊記錄器 v4.22

此壓縮檔包含：

- `index.html`：足球場邊記錄器 v4.22 主程式
- `README.md`：本說明文件

## 使用方式

### 本機開啟
直接用瀏覽器開啟 `index.html` 即可使用。

### GitHub Pages
將 `index.html` 上傳到 GitHub Pages 專案根目錄，並確認檔名維持為 `index.html`。

## 版本
v4.22

## 本版重點
- 修正 iPhone Safari 底部工具列遮住「紀錄」按鈕的問題。
- 依照 visual viewport 動態保留底部可捲動空間，Safari 工具列展開或收合時都能維持可見範圍。
- 「本場事件」模組底部增加少量呼吸空間，確保紀錄卡可完整顯示。
- 不改變主事件／黃紅牌／紀錄的既有分組與操作邏輯。
