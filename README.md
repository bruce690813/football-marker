# 足球場邊記錄器 v4.08

此壓縮檔包含：

- `index.html`：足球場邊記錄器 v4.08 主程式
- `README.md`：本說明文件

## 使用方式

### 本機開啟
直接用瀏覽器開啟 `index.html` 即可使用。

### GitHub Pages
將 `index.html` 上傳到 GitHub Pages 專案根目錄，並確認檔名維持為 `index.html`。

## 版本
v4.08

## 本版重點
- 紀錄按鈕統一為單一淺藍底色，移除左側異色飾條。
- 摘要中的黃牌、紅牌改為直向長方形顯示。
- 延續既有比分、事件、名單、守門員、時間紀錄、摘要與 CSV 匯出功能。
