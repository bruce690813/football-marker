# 足球場邊記錄器 v4.50

此壓縮檔包含：

- `index.html`：足球場邊記錄器 v4.50 主程式
- `README.md`：本說明文件

## 使用方式

### 本機開啟
直接用瀏覽器開啟 `index.html` 即可使用。

### GitHub Pages
將 `index.html` 上傳到 GitHub Pages 專案根目錄，並確認檔名維持為 `index.html`。

## 版本
v4.50

## 本版重點

### 1. 修正 iPhone Safari「＋ 新比賽」被底部工具列截住
- 不再只依賴 `padding-bottom`。
- 在全場頁最底部加入真正存在於文件流的安全 spacer。
- 一般手機約保留 118px；iPhone 小螢幕提高到約 132～140px，再加上 safe-area。
- 使用者可以把「＋ 新比賽」完整捲到 Safari 底部工具列上方。

### 2. 區分「事件紀錄」與「＋ 新比賽」
- 「事件紀錄」維持深石墨藍工具列，表示查看 / 管理既有資料。
- 「＋ 新比賽」改為深藍黑底 + 青藍 outline CTA。
- 新比賽左側加入細 cyan 導引亮條，表示「下一步」而不是另一個資料入口。
- 避免兩顆按鈕使用相近灰藍實心底色造成視覺混淆。

### 3. 不影響既有功能
- 比分、事件、黃紅牌、PK、摘要、儲存圖片、CSV 匯出等邏輯不變。
