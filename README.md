# 足球場邊記錄器 v3.70

## 本版重點

v3.70 保留 v3.69 的 UI / UX 改善，但移除 PWA 額外檔案，
重新回到簡單、容易部署的 GitHub Pages 架構。

## 部署檔案

網站實際執行只需要：

- `index.html`

`README.md` 僅作為版本與部署說明文件，不影響網站執行。

## 已移除

- `manifest.webmanifest`
- `service-worker.js`
- `<link rel="manifest">`
- Service Worker 註冊程式

因此不再使用 Service Worker 離線快取，
降低 GitHub Pages 更新後仍顯示舊版內容的風險。

## 保留的 v3.69 UI / UX 改善

### Live 專注模式
比賽開始後：
- 收起賽事名稱與場地輸入列
- 隱藏 `＋新比賽`
- GK 與本場球員名單改為精簡快捷操作
- 若已有賽事名稱 / 場地，以精簡資訊列顯示

### 時間紀錄精簡
比賽中預設只保留「時間紀錄 / 展開」，
開始時間、結束時間與其他詳細資訊需要時再展開。

### 3 秒快速復原
事件標記完成後會短暫顯示快速復原提示，
可直接撤銷剛剛標記的事件，不必進入紀錄清單刪除。

### 長隊名自動縮字
長隊名會依字數自動降低字級，
減少隊名與中央比分互相擠壓。

## 正式事件類型

- ⚽ 進球
- 🧤 撲救
- 🥅 射門
- 🛡️ 防守
- 🟨 黃牌
- 🟥 紅牌

`精彩配合` 與 `精彩防守` 已於 v3.68 起完全移除。

將 ZIP 解壓後：
