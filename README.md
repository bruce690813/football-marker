# 足球場邊記錄器 v2.76

## 主畫面比賽狀態 badge 調整

新版依實際操作流程顯示，不預設每一場都有上下半場：

- 賽前：`賽前`
- 一般比賽進行中：`LIVE 比賽中`
- 第一次結束後若選擇「還有下半場」：`中場`
- 下半場開始後：`LIVE 下半場`
- 全場結束：`全場`

已移除主畫面的 `PRE / 1ST / HT / 2ND / FT`。

第一段開始時不顯示「上半場」，因為此時系統尚未知道這場是否還有下半場；只有使用者在第一次結束時選擇「還有下半場」後，系統才正式切換為上下半場模式。


- 調整「紀錄」按鈕字級與圖示尺寸，與主要事件按鈕（如進球）更一致。
- 「紀錄」按鈕高度同步提升，視覺層級更明顯。


- 「紀錄」按鈕改為完全比照事件按鈕（如進球）的字級與高度設定。
- 「紀錄」圖示、文字行高與版面間距同步對齊事件按鈕視覺。
