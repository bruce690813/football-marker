# 足球場邊記錄器 v4.17

此壓縮檔包含：

- `index.html`：足球場邊記錄器 v4.17 主程式
- `README.md`：本說明文件

## 使用方式

### 本機開啟
直接用瀏覽器開啟 `index.html` 即可使用。

### GitHub Pages
將 `index.html` 上傳到 GitHub Pages 專案根目錄，並確認檔名維持為 `index.html`。

## 本版重點
- 修正「忠義國小」等四字隊名被顯示成「忠義…」的問題。
- 移除比分區球隊名稱的省略號機制。
- 1～8 字隊名依左右欄實際寬度自動縮小字級，優先完整單行顯示。
- 9 字以上才允許兩行顯示，兼顧長隊名與版面穩定。
- 畫面尺寸改變時會重新計算字級，避免 iPhone 不同寬度造成截字。
