# 足球場邊記錄器 v3.93

## 場地選單改為「實際使用累積型」

v3.93 不預先加入任何場地範本。

場地清單只收錄使用者實際輸入 / 使用過的場地，
讓清單自然變成自己的常用比賽場地。

### 累積規則

- 第一次使用：清單可為空
- 手動輸入有效場地後，自動加入最近使用
- 同名場地不重複
- 再次使用同一場地時，自動移到最前面
- 最多保留 8 筆
- 超過 8 筆時，自動淘汰最久未使用的一筆

### 手動輸入

下拉選單持續保留：

`✎ 手動輸入其他場地`

因此不在清單裡的場地仍可以直接輸入。

### 刪除誤輸入場地

每個最近場地右側新增低調：

`×`

可直接刪除誤輸入或已不需要的場地。

如果刪除的場地同時是「上次使用場地」，
程式也會同步移除該記憶，避免下一次打開清單又自動出現。

### 空清單提示

若尚未累積任何場地，顯示：

`尚無最近使用場地`
`手動輸入後會自動累積`

不會提供預設範本干擾實際使用。

其他功能維持 v3.92。
