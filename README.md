# 足球場邊記錄器 v6.156｜電影風格精簡版海報正式交付

版本日期：2026-10-31

## 開發基準
- 唯一正式原始設計與功能基準仍為 `football_marker_v6_51.zip`；v6.52、v6.53 作廢，不得使用。
- 本次以累加修正後的 `football_marker_v6_155.zip` **直接作為修改基底**。只修改視覺精簡版的 Canvas 產圖程式、加入內嵌電影風格素材與更新版本文字；未重構其他程式。

## 本版完成內容
1. 以獨立場景構圖重新合成第二張視覺精簡版：強調晴空、球場燈、看台、綠茵場、金色記憶球及插畫人物。
2. 在嵌入背景前，清除固定的範例賽事文字、比分、統計與球員背號區域，**正式圖片由 Canvas 使用當前比賽資料重繪**，避免其他賽事殘留 4:1、A STAR 等範例內容。
3. 新版深藍金屬比分牌、金色主比分、球衣動態套色、勝負標記與隊牌。四項統計使用一致的圖示中心與文字基線。
4. MVP 金色舞台可動態顯示最多 8 位並列球員的背號；無 MVP 時顯示成長字句。詳細事件時間軸仍僅在詳細版中。
5. 保留樂樂托著金色記憶球的電影風格插畫。球體內是代表足球攻門的**藝術情境，不是該場真實照片**；不將任何虛構的進球故事當作比賽事實。
6. 「分享/儲存圖片」一次產生詳細版與視覺精簡版兩張圖的邏輯完全沿用 v6.155；詳細版、CSV、賽前/比賽中/中場/下半場/延長賽/PK 等原始程式未修改。
7. 所有美術素材均離線內嵌於 `index.html`，不依賴外部 CDN 或 API。

## 操作方法
1. 將 `index.html` 部署到原本網站或開啟在支援的瀏覽器。
2. 完成比賽後打開「比賽摘要」，按「分享/儲存圖片」。
3. 支援多檔分享的瀏覽器會嘗試分享兩張 PNG；不支援時沿用前版備援下載方式。
4. 此正式 ZIP **只有 index.html、README.md、SECURITY_CHECKLIST.md**，實際 PNG 預覽另行提供、不放入 ZIP。

## 繪圖與靜態檢查結果
- `index.html` 的 4 個內嵌 JavaScript 腳本，Node.js `--check`：**通過**。
- v6.155 → v6.156 前後比對：除版本文字與精簡版 Canvas 產圖區段外，其餘 HTML/CSS/JS 字節內容相同：**通過**。
