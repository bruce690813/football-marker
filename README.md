# 足球場邊記錄器 v4.93

## 本版重點：我方球隊名稱不再阻擋開始比賽

### 實務情境
場邊最重要的是裁判吹哨後能立刻開始計時。

如果這時才跳出「請輸入我方球隊名稱」，使用者還要臨時輸入文字，
會造成操作不順，也可能讓比賽開始時間產生誤差。

## v4.93 採用方案 B

### 1. 我方球隊名稱改為「可稍後補充」
即使沒有輸入我方球隊名稱：

- `▶ 開始比賽` 仍可直接按
- 比賽立即開始計時
- 不跳阻斷式 Modal
- 不要求先輸入文字

### 2. 空白時先顯示「我方」
畫面與後續事件會先使用：

`我方`

作為暫代名稱。

之後可直接點「我方」補上正式球隊名稱。

### 3. 非阻斷提示
若空白隊名直接開賽，畫面會短暫顯示：

- `⏱ 已開始計時`
- `我方球隊名稱可稍後點「我方」補充`

提示不會擋住計時，也不需要按確認。

### 4. 常用隊名記憶保護
空白開賽時不會把空白寫進「最近使用的我方隊名」。

若使用者之前有常用球隊名稱，仍會保留供下一場使用。

### 5. 重新整理也不會偷偷改掉本場隊名
如果本場是用空白名稱開賽：

- 重新整理頁面後仍維持本場「我方」暫代狀態
- 不會被之前記憶的球隊名稱覆蓋

### 6. 其他欄位
下列資料本來就可以稍後補，本版維持：

- 對手
- 賽事名稱
- 場地

## UX 原則

優先順序改為：

**裁判哨音 → 立即開始計時 → 事件記錄 → 有空再補資料**

這比「資料填完整才能開始」更符合真正球場上的使用情境。

## 固定發版檔案

之後每個版本的 ZIP 固定包含：

- `index.html`
- `README.md`
- `SECURITY_CHECKLIST.md`

`SECURITY_CHECKLIST.md` 作為每次改版的安全、資料完整性與發版同步檢查基準，避免更新程式時漏掉相關檢查項目。
