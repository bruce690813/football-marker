# 足球場邊記錄器 v4.81

## 本版重點

### 1) 進球事件在事件紀錄中再提升一級
- 進球事件卡片改為更明顯的綠色重點樣式。
- 增加更清楚的主視覺層級：
  - 卡片背景更亮一階
  - 邊框與左側 accent 更明顯
  - 進球時間與事件文字更突出
  - 比分顯示改為綠色膠囊樣式
  - 加上「關鍵」小標籤，讓進球比一般事件更醒目

### 2) 修正事件紀錄比分顯示邏輯
- 修正 v4.80 中事件紀錄分數區塊的顯示程式。
- 目前策略維持：
  - **進球事件顯示比分**
  - **一般事件不強制顯示比分**
- 這樣可以保留重要資訊，同時避免事件列表出現太多重複的 `0:0`。
