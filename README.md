# 足球場邊記錄器 v3.45

## 本版新增：賽事名稱

首頁在「場地 / GK / 新比賽」下方新增：
`🏆 賽事名稱｜例如：新北市聯賽`

- 選填，不影響開始比賽
- 最多 20 個字
- 視覺高度低於主要操作區，避免破壞既有版面
- 建立新比賽時保留目前賽事名稱，方便同一賽事連續記錄多場

同步輸出至：
- 網頁比賽摘要
- PNG 分享 / 儲存圖片
- HTML 摘要
- CSV（新增 `competition` 欄位）

其他功能維持不變。


## v3.45 更新
- 賽事名稱維持靠左排列。
- 已輸入的賽事名稱字體放大為 16px、字重提高為 800。
- Placeholder 維持較低視覺權重，避免搶過比分與比賽狀態。
