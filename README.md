# 足球場邊記錄器 v4.93

## 本版重點：我方球隊名稱不再阻擋開始比賽

### 實務情境
場邊最重要的是裁判吹哨後能立刻開始計時。

如果這時才跳出「請輸入我方球隊名稱」，使用者還要臨時輸入文字，
會造成操作不順，也可能讓比賽開始時間產生誤差。

## v4.93 採用方案 B

### 1. 我方球隊名稱改為「可稍後補充」
即使沒有輸入我方球隊名稱：

- `▶ 開始比賽` 仍可直接按
- 比賽立即開始計時
- 不跳阻斷式 Modal
- 不要求先輸入文字

### 2. 空白時先顯示「我方」
畫面與後續事件會先使用：

`我方`

作為暫代名稱。

之後可直接點「我方」補上正式球隊名稱。

### 3. 非阻斷提示
若空白隊名直接開賽，畫面會短暫顯示：

- `⏱ 已開始計時`
- `我方球隊名稱可稍後點「我方」補充`

提示不會擋住計時，也不需要按確認。

### 4. 常用隊名記憶保護
空白開賽時不會把空白寫進「最近使用的我方隊名」。

若使用者之前有常用球隊名稱，仍會保留供下一場使用。

### 5. 重新整理也不會偷偷改掉本場隊名
如果本場是用空白名稱開賽：

- 重新整理頁面後仍維持本場「我方」暫代狀態
- 不會被之前記憶的球隊名稱覆蓋

### 6. 其他欄位
下列資料本來就可以稍後補，本版維持：

- 對手
- 賽事名稱
- 場地

## UX 原則

優先順序改為：

**裁判哨音 → 立即開始計時 → 事件記錄 → 有空再補資料**

這比「資料填完整才能開始」更符合真正球場上的使用情境。

## v4.94 事件紀錄 UI 精簡

完整事件紀錄改成「每筆最多兩列」：

第一列：
`時間 + 球隊`

第二列：
`事件圖示 + 背號 + 事件名稱 + 比分 / 助攻`

例如：

`00:02  我方`
`⚽ #36 · 進球  1:0  助攻 #11`

主要效益：

- 球隊名稱不再獨佔第三列。
- 單筆事件高度由約 86–90px 降到約 72–74px。
- 同一個 iPhone 畫面可以看到更多事件。
- 球隊名稱過長時會單行省略，不會撐高卡片。
- 管理按鈕視覺面積縮小到約 34px，但實際可點擊範圍仍維持 44×44px。
- 編輯 / 刪除仍維持「單一管理按鈕 → Action Sheet」流程。


## v4.95 事件紀錄資訊順序優化

完整事件紀錄維持「每筆最多兩列」，但重新依照場邊快速閱讀邏輯排列：

第一列：

`時間 → 球隊 → 球員背號`

第二列：

`事件圖示 → 事件名稱 → 比分 / 助攻`

例如：

`00:02  我方  #36`
`⚽ 進球  1:0  助攻 #11`

`00:07  我方  #31`
`🧤 撲救`

### UI/UX 效益

- 閱讀順序變成「什麼時間 → 哪一隊 / 哪位球員 → 發生什麼」。
- 球隊與球員背號集中在第一列，人物辨識更快。
- 第二列只負責事件語意，進球、撲救、射門、防守、黃牌、紅牌更容易垂直掃描。
- 球員背號固定保留；長球隊名稱會優先省略，不會把背號擠掉。
- 進球的比分與助攻仍放在事件列，不增加第三列。
- 管理按鈕維持 v4.94 的小型視覺、44×44px 實際觸控範圍。


## v4.96 事件紀錄黃牌 / 紅牌色彩強化

本版保留 v4.95 的兩列 Compact 事件紀錄版型，只調整黃牌與紅牌的視覺飽和度。

### 黃牌
- 卡片圖示改為更接近純黃的 `#FFD400` 色系。
- 移除原本偏淡、偏奶油黃的感覺。
- 左側事件 accent 同步改為高飽和黃色。
- 黃牌事件時間使用更明亮的黃色。
- 事件卡只增加非常輕微的黃邊，不整張染黃，避免畫面過度花俏。

### 紅牌
- 卡片圖示改為更鮮明的 `#FF3131 / #FF2D2D` 色系。
- 移除原本偏粉紅的上緣。
- 左側事件 accent 同步改為高飽和紅色。
- 紅牌時間由淡粉紅改成更明確的紅色。
- 紅牌卡片邊框稍微加強，維持其高優先級事件辨識度。

### 設計原則
- 「牌本身」負責傳達黃 / 紅色。
- 事件名稱仍維持白字，避免整列過度著色。
- 不改變 v4.95 的資訊順序與管理按鈕操作。


## v4.97 事件紀錄細節修正

### 球隊與球員背號
v4.96 中球隊名稱使用可伸展的 flex 區塊，因此即使隊名只有「我」，球員背號仍可能被推到右側，看起來像兩組不相關資訊。

v4.97 改成：

`00:02  我 #36`
`⚽ 進球  1:0  助攻 #11`

設計方式：

- 球隊名稱與背號合併成同一個 `WHO` 群組。
- 背號固定緊接在隊名後面。
- 長隊名才使用省略號。
- 即使隊名很長，背號仍優先保留，不會被擠掉。

### 紅牌卡片
紅牌不再使用整張紅色底色。

現在紅牌的高優先級只由以下元素表達：

- 左側鮮紅 accent
- 高飽和紅色長方形牌卡
- 紅色時間

事件卡背景則恢復與一般事件一致的中性深色，避免整張紅底過重、破壞事件列表一致性。
