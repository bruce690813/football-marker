# 足球場邊記錄器 v3.71

## 本版重點：全場結果模式與戶外可讀性

### 1. 全場後隱藏開始 / 結束按鈕
比賽進入「全場」後：

- `▶ 開始比賽`
- `■ 比賽結束`

兩個按鈕都會自動畫面退場。

原因：
- 全場後兩者都已不可操作
- 留著灰色按鈕沒有資訊價值
- 可把高度讓給賽後摘要資訊

只影響全場狀態。
賽前、比賽中、中場、延長賽與 PK 流程維持原本邏輯。

### 2. 「本場標記事件」字級放大
全場後：
- 標題放大
- `進球 / 射門 / 撲救 / 防守` 放大
- 四個統計數字明顯放大
- 增加每格最小高度

目的：
讓使用者在球場戶外環境下也能快速讀取，不需要貼近手機看。

### 3. 「距規定時間」戶外可讀性提升
比賽進入最後 1 分鐘時：
- 提示字級由原本小字放大
- 膠囊高度增加
- 黃 / 橙 / 紅提示對比加強
- 邊框加強
- 保持單行，不壓縮主計時

例如：
`距規定時間 00:38`

會比 v3.70 更容易在大太陽下辨識。

## 其他功能
維持 v3.70：
- Live 專注模式
- 3 秒快速復原
- 長隊名自動縮字
- 比賽中時間紀錄精簡
- 進球 / 撲救 / 射門 / 防守 / 黃牌 / 紅牌
- 摘要 / 儲存圖片 / CSV
- PK / 延長賽
