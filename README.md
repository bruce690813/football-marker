# 足球場邊記錄器 v4.19

此壓縮檔包含：

- `index.html`：足球場邊記錄器 v4.19 主程式
- `README.md`：本說明文件

## 使用方式

### 本機開啟
直接用瀏覽器開啟 `index.html` 即可使用。

### GitHub Pages
將 `index.html` 上傳到 GitHub Pages 專案根目錄，並確認檔名維持為 `index.html`。

## 版本
v4.19

## 本版重點
- 將「進球／射門／撲救／防守」、「黃牌／紅牌」與「紀錄」整合到同一個「本場事件」外框。
- 保留主事件為最高操作層，牌卡事件次一層，紀錄則作為事件管理入口，符合場邊即時記錄的使用邏輯。
- 降低原本三塊獨立外框的分裂感，讓事件模組更一致、更專業。
- 延續既有玻璃感框線與高對比按鈕設計。
