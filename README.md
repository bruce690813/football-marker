# 足球場邊記錄器 v3.85

## 本版修正

### 1. 修正全場「紀錄」被底部工具列遮住
全場後固定在底部的操作現在有兩列：

- 摘要 / 儲存圖片 / 匯出 CSV
- ＋ 新比賽

因此 v3.85 增加全場頁底部安全空間，
讓「紀錄」卡可以完整捲動到固定工具列上方，不再被遮住。

### 2. 賽前「↻ 重設」重新設計
`↻ 重設` 仍位於「賽前」狀態列右側，
但改成較輕量的 outline / text action：

- 不再像第二顆大型主按鈕
- 垂直位置重新調整
- 與「賽前」狀態列更協調
- 維持低視覺權重

### 3. 重設真正清空本場設定
按下 `↻ 重設` 並確認後，清除：

- 賽事名稱
- 比賽場地
- 對手
- 本場名單
- 守門員
- 規定時間
- 比分與其他尚未開始的本場狀態

只保留常用我方隊名（例如忠義）。

場地雖然仍可保留在 LocalStorage 作為未來新比賽的記憶，
但這次按「重設」後，當前畫面的場地一定會清空。

### 4. 黃牌 / 紅牌圖示改為直向長方形
黃牌與紅牌不再使用接近正方形的視覺比例。

v3.85 改為接近真實足球裁判卡牌的直向長方形：

- 黃牌：黃色直向長方形
- 紅牌：紅色直向長方形
- 圓角極小
- 保持戶外辨識度

其他功能維持 v3.84。
