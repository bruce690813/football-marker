# 足球場邊記錄器 v3.09

## 新增：黃牌 / 紅牌紀錄

本版依照現有手機介面新增一顆統一的「🟨🟥 牌卡」按鈕，不把黃牌與紅牌拆成兩顆主按鈕，避免事件區變得擁擠。

### 操作流程
1. 比賽進行中按「🟨🟥 牌卡」。
2. 選擇「🟨 黃牌」或「🟥 紅牌」。
3. 選擇我方或對手。
4. 指定拿牌球員背號：
   - 我方可直接選常用背號。
   - 也可輸入其他 1–99 背號。
   - 背號為選填，可以略過。
5. 系統自動記錄當下比賽時間與比分。

### 紀錄整合
- 黃牌 / 紅牌會加入「紀錄」清單。
- 可於紀錄編輯視窗修改：
  - 事件類型
  - 球隊
  - 球員背號
- 原始標記時間維持不變。
- 比賽摘要、圖片報告及 CSV 會把牌卡視為一般比賽事件呈現。
- 牌卡事件不會改動正式比分。

### UI 原則
- 保留原本 2×2 的進球 / 撲救 / 射門 / 精彩配合主操作區。
- 牌卡採獨立、較精簡的次要事件按鈕，位於事件區與「紀錄」之間。
