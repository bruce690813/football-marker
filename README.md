# 足球場邊記錄器 v4.23

此壓縮檔包含：

- `index.html`：足球場邊記錄器 v4.23 主程式
- `README.md`：本說明文件

## 本版修正
- 再次修正 iPhone Safari 底部工具列遮住「紀錄」按鈕的問題。
- v4.22 原本依賴 `visualViewport` 計算底部工具列高度，但部分 iOS Safari 狀態會回傳接近 0 的差值，因此安全距離不足。
- v4.23 加入固定安全下限與 iOS 專用文件流 spacer，不再只依賴動態偵測。
- 「紀錄」區加入 scroll-margin，滑到頁面底部時可完整停在 Safari 工具列上方。
- 保留目前「本場事件 → 牌卡 → 紀錄」的視覺層級與間距。
