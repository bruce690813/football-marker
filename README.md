# 足球場邊記錄器 v2.45

## 上下半場 / 單段比賽自動支援
- 一開始不需要選擇賽制。
- 第一次按「比賽結束」時才詢問：
  - 全場結束
  - 還有下半場
- 選「全場結束」：維持一般單段比賽流程。
- 選「還有下半場」：
  - 封存上半場時間與事件。
  - 保留累積比分。
  - 首頁改顯示「開始下半場」。
  - 下半場計時重新從 00:00 開始。
  - 下半場事件繼續加入同一場比賽。
- 最終摘要整合上下半場全部球員進球與精彩事件。
- 摘要會顯示上半場 / 下半場各自比分與時間。
- 紀錄視窗中的事件會標記上半場 / 下半場。
- CSV 新增 period / period_label 欄位；seconds 仍代表該半場自己的時間。
