# 足球精彩標記器 v2.15 — 極簡操作版

這版主要精簡主畫面：

- 移除 HTML 報表按鈕
- 移除 JSON 備份按鈕
- 移除手動「儲存」按鈕
- 保留自動儲存機制，所有重要操作後仍會自動寫入手機瀏覽器
- 主畫面只留下真正會使用到的功能：
  - ↶ 復原
  - ☰ 紀錄
  - 📋 摘要
  - 🖼 儲存圖片
  - 分享 CSV
  - 下載 CSV

用途：
- 圖片：給家長 / 教練 / LINE 群組查看
- CSV：給 Mac 剪輯程式使用
- 手機資料：操作過程自動儲存在瀏覽器，不需要額外按儲存

檔案：
- index.html：GitHub Pages 手機版
- marker_clip_tool_v2_15.py：Mac 剪輯工具
- start_mac.command：Mac 雙擊啟動
