# 足球場邊記錄器 v4.21

此壓縮檔包含：

- `index.html`：足球場邊記錄器 v4.21 主程式
- `README.md`：本說明文件

## 使用方式

### 本機開啟
直接用瀏覽器開啟 `index.html` 即可使用。

### GitHub Pages
將 `index.html` 上傳到 GitHub Pages 專案根目錄，並確認檔名維持為 `index.html`。

## 版本
v4.21

## 本版重點
- 重新規劃「本場事件」模組內的垂直節奏。
- 主事件按鈕與黃／紅牌之間增加較明顯的留白與細分隔線。
- 黃／紅牌與「紀錄」之間增加獨立間距，避免三個操作層黏在一起。
- 保留同一個「本場事件」大外框，但透過留白建立「主事件 → 牌卡 → 紀錄」的清楚層級。
- 窄螢幕另外降低間距，兼顧 iPhone 顯示高度。
