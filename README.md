# 足球場邊記錄器 v3.81

## 修正：全場後重新提供「＋ 新比賽」

v3.79 / v3.80 將全場後的大型賽事名稱 / 場地欄位隱藏，
原本放在該區塊內的 `＋ 新比賽` 也因此一起被隱藏。

v3.81 將「新比賽」移到更合理的賽後位置。

### 全場操作順序
1. 比賽結果
2. 本場標記事件
3. 紀錄
4. 摘要 / 儲存圖片 / 匯出 CSV
5. `＋ 新比賽`

### 新比賽按鈕
- 只在全場狀態顯示
- 賽前 / 比賽中 / 中場 / 等待延長賽不顯示
- 使用深藍灰 Slate 色
- 視覺權重低於摘要 / 圖片 / CSV
- 按下後沿用既有 `newMatch()` 流程與確認機制

其他功能維持 v3.80 不變。
