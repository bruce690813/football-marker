# 足球場邊記錄器 v4.52

此壓縮檔包含：

- `index.html`：足球場邊記錄器 v4.52 主程式
- `README.md`：本說明文件

## 本版重點
- 「本場事件統計」四張卡片只有在該事件 > 0 筆時才可點擊查看細節。
- 0 筆時：
  - 卡片不可點擊
  - 不顯示右上角 `›`
  - 視覺稍微降亮，明確表示只是統計資訊
- 有 1 筆以上時：
  - 保持可點擊
  - 顯示 `›`
  - 可進入該事件細節
- 另外在事件細節 handler 再加一道資料檢查，避免 0 筆狀態被其他方式誤觸進入。
- 其他比分、勝方「勝」印章、事件、牌卡、摘要與匯出功能皆維持 v4.51 邏輯。
