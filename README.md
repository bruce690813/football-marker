# 足球場邊記錄器 v3.18

## 新增：助攻紀錄

助攻不新增首頁大按鈕，而是整合進「進球」流程，避免增加場邊操作負擔。

### 操作流程
1. 按「⚽ 進球」
2. 選擇我方 / 對手
3. 選擇進球球員背號或略過
4. 進球先完成並更新比分
5. 自動詢問「是否有助攻？」
6. 可選助攻球員背號，或直接「略過助攻」

### 助攻背號
- 選填。
- 限定 `1～99`。
- 我方可直接使用常用背號。
- 其他背號可手動輸入。
- 對手助攻可手動輸入或略過。
- 助攻球員不可與同一球的進球球員為相同背號。
- 我方有效助攻背號會加入常用背號。

### 資料呈現
助攻資訊同步加入：
- 本場事件紀錄
- 比賽摘要的進球紀錄
- PNG 分享 / 儲存圖片
- HTML 報告
- CSV 匯出（新增 `assist_number` 欄位）

顯示範例：
`進球 · 忠義 #21　助攻 #7　1:0`

### 事後修正
「編輯事件紀錄」在事件類型為進球時，會額外顯示「助攻球員背號」欄位，可補登、修改或清除。

### 相容性
舊版既有比賽紀錄沒有 `assist_number` 時會自動視為空白，不影響既有資料。
