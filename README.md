# 足球場邊記錄器 v5.03

手機場邊即時記錄足球比賽事件的單頁工具。

目前版本：**v5.03**

## v5.01 本版重點

### 快速使用指南
「這是什麼？」新增：

`📖 快速使用指南`

內容以 5 個步驟說明使用流程：

1. 賽前設定
2. 裁判吹哨就開始
3. 場邊一鍵標記事件
4. 中場 / 下半場 / 延長賽 / PK
5. 賽後摘要、儲存圖片與 CSV

另外提供「場邊小技巧」：

> 時間與事件最重要；球隊名稱、賽事名稱與場地來不及輸入時，可以稍後再補。

「快速使用指南」屬於次要入口，主畫面的操作流程維持簡潔。

## 目前主要功能

### 比賽流程
- 賽前
- 比賽中
- 中場
- 下半場
- 延長賽
- PK
- 全場

### 賽事資訊
- 賽事名稱
- 場地
- 本場名單
- 守門員
- 我方 / 對手比分

主要比賽狀態固定：

- 左：`👕 名單 / 人數`
- 右：`🧤 守門員 / 背號`

PK 也保留名單與守門員資訊，並與其他比賽狀態使用一致的賽事 / 場地資訊列。

### 場邊事件
- ⚽ 進球
- 🧤 撲救
- 🥅 射門
- 🛡️ 防守
- 黃牌
- 紅牌

事件紀錄採 Compact 兩列式資訊架構：

第一列：

`時間 → 球隊 → 球員背號`

第二列：

`事件圖示 → 事件名稱 → 比分 / 助攻`

事件管理使用單一 `•••` 按鈕，再選擇：

- 編輯事件
- 刪除事件

### 賽後整理
- 本場事件統計
- 完整事件紀錄
- 比賽摘要
- 儲存圖片
- 匯出 CSV
- 新比賽

## 重要 UX 規則

### 開賽優先
我方球隊名稱空白時仍可立即開始比賽。

裁判吹哨後優先順序為：

`立即開始計時 → 記錄事件 → 有空再補資料`

### 資訊位置一致
從賽前到比賽進行期間：

- 名單固定在左
- 守門員固定在右

避免狀態切換時位置改變。

### 版本資訊
- 主畫面保留版本號，方便確認 GitHub Pages / Safari 快取。
- 「這是什麼？」Header 不強調版本。
- About 底部以低調文字顯示目前版本。

## v5.02 「這是什麼？」Footer UI 精修

### 原本問題
v5.01 底部依序為：

- `版本 v5.01`
- 大框 `📖 快速使用指南`
- 大框 `開始記錄比賽`

三個元素都以獨立橫列呈現，造成底部視覺較擁擠，而且「快速使用指南」與主要 CTA 太接近。

### v5.02 調整
改成：

`📖 快速使用指南 ›                         v5.02`

下方保留唯一主要 CTA：

`開始記錄比賽`

### UI/UX 原則
- 快速使用指南改為輕量文字型次要入口。
- 實際觸控高度仍至少 44px，不犧牲 iPhone 操作性。
- 版本資訊改成純 `v5.02` metadata，不再單獨佔一列。
- 輔助資訊列與「開始記錄比賽」之間增加留白。
- 「開始記錄比賽」維持畫面唯一 Primary CTA。


## v5.03 事件紀錄時間欄位一致化

### 調整內容
事件紀錄中所有事件的時間欄位統一為：

- 字級：16px
- 字重：950
- 顏色：`#FACC15`
- 不使用額外陰影
- 不因事件種類改變大小或顏色

包含：

- 進球
- 撲救
- 射門
- 防守
- 黃牌
- 紅牌

### UI/UX 原則
時間欄位只負責回答：

`WHEN：什麼時間發生`

事件種類則由下列元素表達：

- 左側事件色條
- 事件圖示
- 事件名稱
- 進球比分
- 黃牌 / 紅牌高飽和卡片

因此不再用「時間變紅 / 變淡黃 / 放大」重複表達事件重要性。

時段標籤（上半場 / 下半場等）維持原本藍色 pill，不受影響。
