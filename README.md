# 足球場邊記錄器 v3.80

## Outdoor Contrast Tune｜戶外強日照可讀性

本工具主要使用情境是足球場戶外環境，因此 v3.80
針對陽光下最容易消失的「中灰階資訊」做對比強化。

### 1. 對手名稱
原本灰色較暗。

v3.80：
- 提高文字亮度
- 保持灰白色，不改成純白
- 仍低於我方與中央比分的視覺權重

### 2. 時間紀錄次要資訊
提升：
- 開始時間 / 結束時間的標籤
- 詳細時間欄位標籤
- 其他次要時間說明

不靠非常細微的深灰 / 淺灰差異維持層級。

### 3. Disabled 狀態
戶外設計原則：

`Disabled ≠ 看不見`

因此：
- 背景仍為灰色
- 文字亮度提高
- 邊框略提高辨識度
- 仍維持灰階與低飽和，不會誤認成可操作按鈕

### 4. 紀錄 0 筆
沒有事件時：
- `紀錄`
- `共 0 筆`

都能在陽光下清楚辨識，
但整張卡仍保持不可操作的 Disabled 視覺。

### 5. 防守紫色
防守按鈕的紫色提高一級亮度與飽和度，
但仍維持：

`防守 = 紫色`

不破壞使用者已建立的顏色與位置記憶。

### 6. 本場標記事件
全場結果卡中的：
- 進球
- 射門
- 撲救
- 防守

次要文字提高亮度，
數字仍使用最高亮度白色。

### 維持不變
- LIVE 紅色
- 中央比分白色
- 進球綠色
- 撲救藍色
- 射門黃色
- 黃牌 / 紅牌
- 足球場極淡背景線

足球場線稿仍然只是裝飾，
不因戶外看不清楚而刻意加亮。

其他功能維持 v3.79。
