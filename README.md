# 足球場邊記錄器 v4.13

此壓縮檔包含：

- `index.html`：足球場邊記錄器 v4.13 主程式
- `README.md`：本說明文件

## 使用方式

### 本機開啟
直接用瀏覽器開啟 `index.html` 即可使用。

### GitHub Pages
將 `index.html` 上傳到 GitHub Pages 專案根目錄，並確認檔名維持為 `index.html`。

## 版本
v4.13

## 本版重點
- 比分數字放大約 12–15%，強化記分板第一視覺焦點。
- 左右比分框小幅加寬，但高度維持原比例，避免版面變得笨重。
- 中央冒號縮小並降低亮度，讓視線集中在黃色比分。
- 10–99 兩位數比分會自動縮字，左右比分框維持固定寬度與對稱。
- 針對較矮螢幕與 390px 以下手機寬度另外調整比例。
- 延續 v4.12 既有 UI/UX、比分、事件、名單、守門員、時間紀錄、摘要與 CSV 匯出功能。
