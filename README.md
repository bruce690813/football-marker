# 足球場邊記錄器 v6.142

## 基底與修改
以 v6.141 ZIP 為直接程式基底，正式開發來源仍遵循 v6.51 專案規範（v6.52、v6.53 作廢）。

僅改善「視覺精簡版」Canvas 圖片：
- 球衣改為動態色票控制的多層漸層與高光，加入衣領、袖口、縫線及陰影。
- 主比分改為金色漸層、描邊、立體投影與柔光效果；保留動態比數。
- 球隊名稱下方增加刷痕隊牌；勝方章增加簡化冠冕效果。
- 四項統計數值增加對比；MVP 改金棕色頒獎舞台色調。
- 背景沿用 v6.141 已內嵌球場素材；不額外要求網路載入。

不修改原詳細版、分享兩張的操作流程、CSV、賽事事件紀錄、手機版 UI，也不在圖片背景中固定賽果文字。

## 實測與限制
- 靜態：4 個內嵌 JavaScript 區塊均通過 Node 語法檢查。
- Chromium：以模擬「忠義國小 4：1 A STAR」資料執行 Canvas，輸出 900×1125 PNG；無 JavaScript pageerror。
- 視覺：測試圖中的比分、隊名、四項統計與四位 MVP 顯示完整。
- 限制：球場背景仍為插畫合成素材，球衣為向量漸層，不等同原始美術參考的寫實球衣、攝影球場與 3D 後製。
- 尚未驗證：真實 iPhone Safari、LINE 多檔分享、所有長隊名/8人 MVP 及整個比賽流程。

測試 PNG 隨交付回覆另外提供，不納入正式 ZIP。
