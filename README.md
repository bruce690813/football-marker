# 足球場邊記錄器 v4.54

此壓縮檔包含：

- `index.html`：足球場邊記錄器 v4.54 主程式
- `README.md`：本說明文件

## 本版修正重點

### 1) 勝方「勝」印章移到比分區
- 將原本顯示在球隊名稱旁的「勝」圓形印章，移到比分區。
- 左隊獲勝時，印章顯示在左側比分框的右下方。
- 右隊獲勝時，印章顯示在右側比分框的左下方。
- 避免遮擋球隊名稱，讓「哪一邊獲勝」仍然一眼可辨識。

### 2) 球隊名稱可讀性維持
- 獲勝方隊名仍保留微亮提示。
- 但不再被勝方印章覆蓋。

### 3) 其他功能維持
- 四張「本場事件統計」卡片仍維持：有資料可點、0 筆不可點。
- 移除 `›` 提示的設計維持不變。
- 比分、PK、事件紀錄、摘要、儲存圖片、匯出 CSV 等功能邏輯不變。
