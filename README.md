# 足球場邊記錄器 v4.31

此壓縮檔包含：

- `index.html`：足球場邊記錄器 v4.31 主程式
- `README.md`：本說明文件

## 使用方式

### 本機開啟
直接用瀏覽器開啟 `index.html` 即可使用。

### GitHub Pages
將 `index.html` 上傳到 GitHub Pages 專案根目錄，並確認檔名維持為 `index.html`。
