# 足球場邊記錄器 v4.70

## 修正：全場「＋ 新比賽」仍被 iPhone Safari 底部工具列遮住

v4.69 主要靠頁尾 Safe Area，實機截圖證明在某些 Safari 工具列狀態下仍不足。
v4.70 改成「三層防護」：

1. **全場工具區 Compact**
   - 本場事件統計稍微降低高度。
   - 摘要 / 儲存圖片 / 匯出 CSV 保持至少 44px 觸控高度。
   - ＋ 新比賽保持至少 48px。

2. **保留真實文件流 Safe Area**
   - iPhone 主流寬度保留 196px。
   - 390px 以下保留 208px。
   - 手動滑到底仍能把最後 CTA 完整拉到工具列上方。

3. **進入全場時自動校正**
   - 檢查「＋ 新比賽」實際 bottom 是否落入 Safari 底部遮蔽區。
   - 若被遮住，只自動捲動「必要距離 + 8px」。
   - 140ms 與 520ms 各校正一次，處理 Safari 動態工具列展開 / 收合。
   - 不會持續強迫捲動；同一場比賽只在進入全場時執行。

## 其他狀態
賽前 / 比賽中 / 中場 / 下半場 UI 不變。
