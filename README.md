# 足球場邊記錄器 v3.38

## 本版調整：導入深綠足球場風格背景

- 依照 UI/UX 建議，將整體頁面背景改為 **深綠足球場氛圍**。
- 採用 **低飽和、低對比** 的處理方式：
  - 外層加入深綠草皮條紋與淡化球場線條。
  - 主操作卡片仍維持深藍黑色高對比，避免影響按鈕、比分與文字辨識。
- 背景定位為 **氛圍層**，不干擾實際操作流程。
- 同步微調卡片外框與陰影，讓主內容與背景融合得更自然。

## 設計原則
- 背景只負責增加「足球場邊」識別感。
- 主要資訊（比分、按鈕、事件）仍保持最高可讀性。
- 不使用過亮草皮或高干擾照片紋理，避免像遊戲介面而不是工具介面。
