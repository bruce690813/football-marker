# 足球場邊記錄器 v4.37

此壓縮檔包含：

- `index.html`：足球場邊記錄器 v4.37 主程式
- `README.md`：本說明文件

## 使用方式

### 本機開啟
直接用瀏覽器開啟 `index.html` 即可使用。

### GitHub Pages
將 `index.html` 上傳到 GitHub Pages 專案根目錄，並確認檔名維持為 `index.html`。

## 版本
v4.37

## 本版重點
- 「規定時間」的分鐘選擇欄位改為獨立一列，避免手機畫面過度擁擠。
- 「套用」與「清除」改成下一列的兩顆等寬大按鈕。
- 按鈕高度提升至約 48–50px，改善粗手指、單手及場邊快速操作的點擊容錯。
- 「套用」維持亮藍主操作；「清除」採低一級灰藍次操作，強化操作層級。
- 自訂分鐘欄位仍位於選單下方，功能與既有操作流程不變。
