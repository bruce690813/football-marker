# 足球場邊記錄器 v3.62

## 修正：賽前欄位自動導引

### 導引順序
**我方 → 對手 → 賽事名稱 → 場地 → 收起鍵盤**

### 本版修正
- 我方輸入完成按 iPhone ✓ 後，自動跳到「對手」。
- 對手完成後，自動跳到「賽事名稱」。
- 賽事名稱完成後，自動跳到「場地」。
- 場地完成後結束導引並收起鍵盤。
- 即使我方原本已有記憶值，重新編輯我方後也會正常啟動導引。
- 同時支援 iPhone Safari 的 Enter 與 blur 行為。
- 對手、賽事名稱、場地仍為選填，空白可以直接往下一步。
- 使用者若主動直接點「場地」或其他欄位，系統會尊重該操作，不會強制拉回前一欄。
- 開始比賽仍只有「我方」必填；其他欄位空白不會阻擋開賽。

其他功能維持不變。
