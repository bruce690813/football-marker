# 足球場邊記錄器 v3.66

## 修正：最後 1 分鐘提醒擠壓主計時器

### 問題
v3.65 的「距規定時間 00:xx」與
`LIVE / 比賽中 / 主計時` 位於同一個橫向 Flex，
在 iPhone 寬度下會搶占主計時器空間，造成提醒文字被壓縮到右側。

### v3.66
改為上下兩層：

第一列：
`● LIVE　比賽中　03:12`

第二列：
`距規定時間 00:48`

### 視覺
- 規定時間提醒改成置中的小型膠囊。
- 60～31 秒：琥珀黃。
- 30～1 秒：橘色。
- 規定時間到 / 超時：紅色。
- 主計時器不再被壓縮或縮小。
- 不改變正向累加計時邏輯。

其他功能維持不變。
