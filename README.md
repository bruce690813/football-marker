# ⚽ 足球場邊記錄器 v6.52

單頁 HTML、手機優先的足球賽事事件記錄器。將 `index.html` 放到 GitHub Pages 或用瀏覽器開啟即可使用，不需要後端伺服器。

## v6.52 視覺精修重點

本次以 **v6.51 整合版** 的程式為基礎，調整 UI/CSS，不重建既有事件操作流程。

1. **賽事／場地改為共享資訊框：** 外部一個柔和邊框、內部只保留一條細分隔線。保留圖示與字級區分。
2. **固定三個比賽狀態的共同設計：** `比賽中（FIRST）`、`下半場（SECOND）`、`延長賽（EXTRA）` 都套用相同的賽事欄位、比分牌、事件按鈕與框線策略。`賽前／中場／結束` 狀態也沿用相同容器規則。
3. **比分區精修：** 黃色翻頁式數字仍是第一視覺焦點，淡化外部框線；LIVE 狀態顯示細小紅點，而非高亮的厚框。
4. **事件按鈕保留鮮明色彩：** 進球（綠）、撲救（藍）、射門（金）、防守（紫）；黃牌／紅牌／比分調整／名單採較低對比的輔助色塊；按鈕之間不另加水平分隔線。
5. **結束比賽按鈕降彩：** 維持紅色危險操作語意，但不搶佔比分與標記事件的注意力。
6. **底部工具列防遮擋：** 主內容在工具列上方的獨立捲動區滾動，事件按鈕不會被固定工具列覆蓋。較短的 iPhone 螢幕可向上滑動檢視下方內容。
7. **字級／高度不變：** Compact 賽事及場地列高度 **38px**、主要名稱 **14.5px**、階段場次 **12px**；Ultra Compact 高度 **35px**、主要名稱 **13.75px**、階段場次 **11.5px**。長名稱仍以省略號處理。
8. **版本號同步：** 網頁標題、主畫面標示、摘要圖片標示與更多工具說明均更新為 v6.52。

## 功能與操作

- 編輯賽事名稱、階段、場次、場地、球隊、規定分鐘數；設定球員名單及守門員。
- 比賽狀態：賽前 → 比賽中 → 中場 → 下半場 → 延長賽 → 結束比賽（延長賽可暫停／繼續）。
- 六種事件：進球、撲救、射門、防守、黃牌、紅牌；可輸入隊伍、球員背號及事件時間，並修改或刪除。
- 比分由進球紀錄推算，可手動調整；單場摘要、球員進球統計、勝場 MVP／非勝場最多進球、圖片分享、CSV 匯出。
- 本機自動儲存、JSON 備份與還原；可切換一般／Compact／Ultra Compact。

## 安裝與資料保護

1. 解壓 `football_marker_v6_52.zip`，取得 `index.html`、`README.md`、`SECURITY_CHECKLIST.md`。
2. 用 Safari／Chrome 開啟 HTML，或將 `index.html` 放到既有 GitHub Pages 網站根目錄。
3. 建議更新前先在舊版「更多工具」備份 JSON；瀏覽器本機資料受到網址／網域限制，直接開檔與部署到網站可能使用不同的儲存空間。

**相容性：** v6.52 沿用本專案 v6.51 整合版的本機儲存鍵 `football_marker_v651_active`，同一網址、同一瀏覽器更新部署時可沿用目前工作區（資料格式未變）。若切換網域或由本機檔轉為 GitHub Pages，需使用備份還原。本版本基於先前重建的 v6.51 ZIP，**並非使用者既有網站原始版本的逐行更新**；其歷史多場管理／PK 等功能若不在 v6.51 ZIP 中，也未於本版加入。
