# 足球場邊記錄器 v3.29

## 修正：iPhone 新比賽輸入引導

- 修正 iPhone 中文鍵盤按右上角 ✓「完成」後，沒有從我方自動跳到對手的問題。
- 原因：iOS 部分中文輸入法按完成只觸發 `blur`，不一定觸發 `keydown Enter`。
- 新版同時支援 `Enter` 與 `blur`，並使用引導狀態避免重複跳欄位。
- 流程：我方 → 對手 → 場地。
- 我方仍為必填；對手與場地維持既有欄位規則。
- 場地完成後會保存符合條件的場地記憶並結束引導。
