# 足球場邊記錄器 v3.16

## 本版新增：進球助攻紀錄

### 我方進球流程
1. 選擇進球球員背號。
2. 系統完成進球紀錄與比分更新。
3. 接著顯示「助攻球員（選填）」。
4. 可選常用背號、手動輸入 1～99，或按「無助攻 / 略過」。

### 助攻規則
- 只有我方進球會詢問助攻，對手進球不增加場邊操作。
- 助攻不建立成另一筆事件，而是附加在原本 GOAL 紀錄內。
- 進球者與助攻者不可使用相同背號。
- 助攻背號可在「紀錄 → 編輯事件」中修改或清除。
- 摘要會顯示例如：`忠義 #7 · 助攻 #21`。
- 球員統計新增助攻，例如：`忠義#21 🅰️1`。
- PNG / HTML 報告 / CSV 均同步帶入助攻資訊。
- CSV 新增 `assist_player_number` 欄位。

## 黃牌 / 紅牌視窗
- 移除黃牌按鈕內重複的小黃色方塊。
- 移除紅牌按鈕內重複的小紅色方塊。
- 保留整顆黃色 / 紅色按鈕與文字，視覺更乾淨。

## 首頁守門員設定
- 維持目前精簡版配置：場地、`🧤 GK / #背號`、新比賽位於同一列。
- 移除「設定後，撲救可一鍵記錄」常駐說明文字。
- 有設定 GK 時，撲救仍會直接套用目前守門員背號。

其他既有功能維持不變。
