# 足球場邊記錄器 v4.07

## 主比分區改為數位翻頁比分牌視覺

### 主要改動
- 左右比分改成各自獨立的深色數位比分牌
- 分數由白色改成 Score Amber 暖黃 `#FFE36E`
- 冒號維持灰白／淡藍，不與比分數字同色
- 每塊比分牌加入非常淡的水平折線，帶出實體翻頁比分牌的設計語彙
- 不加入厚重 3D、金屬框或真實鉸鏈，保持手機 UI 乾淨

### 顯示邏輯
- 0～99 分皆可正常顯示
- 隊名維持白色
- 比分修正功能不變
- 比賽中、中場、下半場、全場都沿用同一套主比分牌視覺

### 戶外可讀性
- 暖黃分數在深藍背景上比純白更聚焦
- 黃色採用獨立的 Score Amber，不與黃牌的純黃完全相同
- 冒號刻意維持灰白，避免整個比分區過度發黃
