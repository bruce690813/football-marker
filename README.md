# 足球場邊記錄器 v6.136

以 v6.135 為直接基礎，維持完整詳細分享圖片，僅於「摘要」新增獨立「分享／儲存視覺精簡版圖片」按鈕。

## 變更
- 原詳細版分享／儲存按鈕保留，改標示「詳細版」。主畫面儲存圖片繼續輸出詳細版。
- 新增 900 × 1125（4:5）Canvas 視覺精簡版，顯示賽事、日期、隊名、全場比分與勝方、四項事件統計、MVP（或我方最多進球）；不輸出事件時間軸。
- 點擊兩種按鈕時各自分享或下載一張圖片，不會強制同時下載兩張。
- 視覺精簡版檔名 `_visual.png`；詳細版原檔名與演算法保留。
- 未修改事件資料、CSV、摘要內容邏輯及手機主畫面布局。

## 使用
比賽結束後 → 摘要 → 點選「分享／儲存詳細版圖片」或「分享／儲存視覺精簡版圖片」。iOS 分享面板中可選「儲存影像」。

## 測試
已進行靜態差異與 JavaScript 語法檢查；瀏覽器 Canvas 視覺效果、iOS 分享面板及完整比賽流程需實機驗證。
