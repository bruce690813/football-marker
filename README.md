# 足球場邊記錄器 v6.160｜指定球員上場時間追蹤

版本日期：2026-10-31

## 開發基準與修改範圍
- **直接基底**：`football_marker_v6_159.zip`。最早正式功能與美術基準仍是 `football_marker_v6_51.zip`；v6.52 與 v6.53 已作廢。
- **本次唯一新增功能**：單一球員上場／下場時間追蹤及獨立 CSV；不改動原事件種類、畫面配色、比分、影像合成、詳細／精簡雙圖分享、守門員、PK 或任何現有 Marker CSV 欄位。
- 僅在賽前／比賽中新增一條精簡入口，透過彈出視窗操作；賽後摘要新增唯讀的追蹤回顧入口。

## 使用流程
1. 賽前按「👕 球員出賽追蹤」，輸入要追蹤的背號 `1–99`，也可選用球員名單的背號建議。
2. 如果開賽就是先發，勾選「第一段開賽即為先發」後按「套用」。在第一段開始時自動從 `00:00` 建立上場區間。若為替補，開賽時不自動記錄，待真正上場後按「↑ 記錄上場」。
3. 比賽中按小入口進入追蹤視窗，按「↓ 記錄下場」結束這次上場區間；稍後再次上場，按「↑ 記錄上場」。若誤按，可撤銷最近一次同段的開／關區間操作。
4. 進入中場或延長賽等待時，系統自動關閉當段仍在場上的區間。開啟追蹤視窗，勾選「下一段開賽即在場上」，新的一段開賽會自動從 `00:00` 開始計算；未勾選時保持場下，須手動記錄上場。**中場休息不計入上場時間**。
5. 每一段已結束的區間皆可按「修正」，使用 `MM:SS` 或 `H:MM:SS` 修改上／下場秒數（受階段長度與區間不重疊檢查保護）。
6. 比賽中可預覽時間軸及累計時數；賽後摘要中也有「球員出賽追蹤」項目，可重新開啟時間軸。按「⬇ 匯出球員上場時間 CSV」取得檔案。
7. 目前**每場只追蹤一位球員**。只要該球員已有任何上場區間或正在場上，就不可改成另一背號，以免不同球員資料混入同一份 CSV。新建下一場時清空追蹤紀錄，不繼承上一場的球員選擇。

## 專屬球員區間 CSV
- 檔名為 `<日期時間>_<球隊>_player_<背號>_onfield.csv`。它與原有 `<日期時間>_<球隊>_<比分>_markers.csv` **分開匯出**。
- 專屬 CSV 欄位為 `match_id, our_team, opponent_team, competition, competition_stage, day_match_number, player_number, period, period_label, start_seconds, end_seconds, duration_seconds, start_time, end_time, start_datetime, end_datetime`（16 欄）。每一列是單一**已完成上場區間**，秒數以各段影片起點為零。
- 正在場上的區間尚未有正式下場時間，**不納入 CSV**；請按下場或完成該階段後再匯出。避免誤把比賽中途的時間當成完整影片片段。
- 假設 #36 上半場 `00:00–12:35`、下半場 `00:00–04:10` 及 `09:00–19:50`：匯出三列，累計出賽時間 `27:35`。這不是場上個人事件精華，而是**整段上場畫面**，故可能有不涉及該球員的場面。
- 現有 Highlight **v2.18 尚不能直接讀取此 16 欄的區間 CSV 進行剪片**；須後續在剪輯程式增加「球員出賽區間」模式，依每半場影片及偏移量擷取時間區間。原 24 欄 Marker CSV 仍維持供既有 Highlight 剪輯使用。

## 儲存與安全
- 上下場資料只存在當場比分記錄器既有的比賽儲存物件內（`state.playerTracking`，localStorage／Match ID 隔離）；重新開啟該場比賽可還原。沒有發送網路 API。
- 匯出區間時使用現有 CSV escaping；時間採全秒精度，驗證球員背號 1～99、階段 1～4、時間非負、不可超過階段長度、不可與其他上場區間重疊。

## 本版完成內容
1. 以獨立場景構圖重新合成第二張視覺精簡版：強調晴空、球場燈、看台、綠茵場、金色記憶球及插畫人物。
2. 在嵌入背景前，清除固定的範例賽事文字、比分、統計與球員背號區域，**正式圖片由 Canvas 使用當前比賽資料重繪**，避免其他賽事殘留 4:1、A STAR 等範例內容。
3. 新版深藍金屬比分牌、金色主比分、球衣動態套色、勝負標記與隊牌。四項統計使用一致的圖示中心與文字基線。
4. MVP 金色舞台可動態顯示最多 8 位並列球員的背號；無 MVP 時顯示成長字句。詳細事件時間軸仍僅在詳細版中。
5. 保留樂樂托著金色記憶球的電影風格插畫。球體內是代表足球攻門的**藝術情境，不是該場真實照片**；不將任何虛構的進球故事當作比賽事實。
6. 「分享/儲存圖片」一次產生詳細版與視覺精簡版兩張圖的邏輯完全沿用 v6.155；詳細版、CSV、賽前/比賽中/中場/下半場/延長賽/PK 等原始程式未修改。
7. 所有美術素材均離線內嵌於 `index.html`，不依賴外部 CDN 或 API。

## 操作方法
1. 將 `index.html` 部署到原本網站或開啟在支援的瀏覽器。
2. 完成比賽後打開「比賽摘要」，按「分享/儲存圖片」。
3. 支援多檔分享的瀏覽器會嘗試分享兩張 PNG；不支援時沿用前版備援下載方式。
4. 此正式 ZIP **只有 index.html、README.md、SECURITY_CHECKLIST.md**，實際 PNG 預覽另行提供、不放入 ZIP。
