# 足球場邊記錄器 v2.22 — 手機單頁版

這版再進一步精簡手機主畫面：

- 移除「CSV 給剪輯程式使用｜資料會自動儲存｜圖片可存到照片」
- 移除「資料會自動儲存在此手機」
- 移除「下載 CSV」
- 保留「分享 CSV」，可直接透過 iPhone 分享面板 AirDrop 到 Mac 或存到檔案
- 最後操作區濃縮成一排：
  - 📋 摘要
  - 🖼 儲存圖片
  - 分享 CSV
- 再縮短卡片、計時區與事件按鈕的垂直高度，盡量讓手機一頁就能看到主要功能

建議用途：
- 摘要：手機直接查看本場紀錄
- 儲存圖片：分享到照片 / 家長群 / LINE
- 分享 CSV：AirDrop 到 Mac 給剪輯程式讀取
