# 足球場邊記錄器 v4.42

此壓縮檔包含：

- `index.html`：足球場邊記錄器 v4.42 主程式
- `README.md`：本說明文件

## 使用方式

### 本機開啟
直接用瀏覽器開啟 `index.html` 即可使用。

### GitHub Pages
將 `index.html` 上傳到 GitHub Pages 專案根目錄，並確認檔名維持為 `index.html`。

## 版本
v4.42

## 本版重點
- 優化「黃 / 紅牌」與「紀錄」兩區過於接近的視覺問題。
- 黃 / 紅牌區改為更深的中性事件底板，讓黃色與紅色牌卡本身成為視覺焦點。
- 黃 / 紅牌上方加入小型「牌卡事件」提示，強化它仍屬於事件輸入。
- 「紀錄」改成深石墨藍工具列風格，降低亮度與飽和度，明確區分為查看 / 管理入口。
- 0 筆 disabled 狀態不再呈現亮藍底，避免和牌卡事件混淆。
- 不改變既有事件操作邏輯、間距結構與中場 / 全場 record-only 緊湊版面。
