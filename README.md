# 足球場邊記錄器 v4.46

此壓縮檔包含：

- `index.html`：足球場邊記錄器 v4.46 主程式
- `README.md`：本說明文件

## 使用方式

### 本機開啟
直接用瀏覽器開啟 `index.html` 即可使用。

### GitHub Pages
將 `index.html` 上傳到 GitHub Pages 專案根目錄，並確認檔名維持為 `index.html`。

## 版本
v4.46

## 本版重點
- 採用強化版視覺層級：將「本場事件統計」與「賽後功能按鈕」做明確分流。
- 保留事件色辨識（進球 / 射門 / 撲救 / 防守），但統計卡改為更偏資訊面板的深色卡片語言。
- 四個統計卡新增更明確的彩色頂條與較深色的卡面，降低與底部操作按鈕混淆。
- 底部賽後按鈕改成主次分層：
  - 摘要：主按鈕（亮青綠）
  - 儲存圖片：次按鈕（功能藍）
  - 匯出 CSV：輔助按鈕（灰藍）
- 整體仍維持深色轉播風格，但讓使用者更容易一眼分辨「資訊」與「操作」。
