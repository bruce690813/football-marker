## v4.12 UI/UX 調整
- 底部「開始使用這個工具」改為固定 CTA 區塊，不再因手機瀏覽器高度而被截掉。
- 介紹文字重新精簡分段，提升閱讀節奏。
- 三張功能卡縮減高度與間距，降低畫面壓迫感。
- 功能卡左側 Accent 統一為品牌藍色系。
- 最下方回憶文案弱化卡片感，改為較像品牌簽名的收尾視覺。
- 右上角關閉按鈕縮小並降低視覺權重。

## 使用
將 `index.html` 上傳至 GitHub Pages 專案根目錄即可。
