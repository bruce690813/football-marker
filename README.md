# 足球場邊記錄器 v4.78

## 黃牌 / 紅牌操作流程 UIUX 收尾

### 1. 選擇球隊也加入真實長方形牌卡
- 黃牌：黃色長方形牌卡 + `黃牌｜選擇球隊`
- 紅牌：紅色長方形牌卡 + `紅牌｜選擇球隊`
- 與下一步 `黃牌／紅牌｜選擇球員` 使用相同事件識別

### 2. 球員頁說明文字精簡
我方：
- `球員背號為選填，可直接略過。`

對手：
- `對手球員背號為選填，可直接略過。`

避免用長文字重複解釋 UI。

### 3. 本場名單來源列正式納入黃 / 紅牌流程
有本場名單時顯示：
- `本場名單`
- `X 人可選`

沒有本場名單時：
- fallback 常用背號

### 4. 維持 6 欄 Player Picker
主流 iPhone：
- 黃牌球員
- 紅牌球員
- 進球者
- 助攻者
- 射門者
- 防守者

維持一致的 6 欄操作語言。

### 5. 對手流程保持簡潔
對手沒有本場 roster，因此仍維持：
- 輸入對手背號
- 略過背號

不加入大量 1–99 按鈕。

## 不變
- 黃牌 / 紅牌事件邏輯
- 紅牌退場限制
- 其他背號
- 略過背號
- 取消事件
- 事件紀錄與比分邏輯
