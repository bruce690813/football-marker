# 足球場邊記錄器 v3.17

## 本版 UI / UX 調整

### 1. 撲救按鈕移除守門員提示小字
- 移除撲救按鈕內的「自動使用 #21」。
- 守門員資訊只保留在上方快捷設定：
  - 未設定：`🧤 GK`
  - 已設定：`🧤 #21`
- 撲救一鍵套用守門員背號的功能不變。

### 2. 守門員整合至場地同一列
首頁上方改為：
`場地 ｜ 🧤 GK / #背號 ｜ ＋新比賽`

減少額外一列說明資訊，讓主畫面更緊湊。

### 3. 本場事件紀錄時間欄位左移
- 「第幾筆」欄位縮窄。
- 時間欄位緊接在第幾筆後方並改為靠左。
- 把更多橫向空間讓給事件、球員背號、球隊與比分資訊。

### 4. 本場事件紀錄移除事件圖示
- 列表不再顯示 ⚽ / 🥅 / 🧤 / 🙌 等事件圖示。
- 保留「進球 / 射門 / 撲救 / 精彩配合 / 黃牌 / 紅牌」文字。
- 主畫面的四個事件按鈕仍保留圖示。
- 編輯與刪除操作仍保留。

此調整讓事件列表更偏向「高密度資料閱讀」，主畫面則維持「快速操作」的視覺語言。
