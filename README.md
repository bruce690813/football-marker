# 足球場邊記錄器 v3.04

本版修正：賽前禁止修改比分

- 賽前比分固定為 `0:0`。
- 「✎ 修正比分」在賽前顯示為禁用狀態。
- 比賽開始後可修正比分。
- 中場等待下半場時仍可修正。
- 全場結束後仍可修正，方便賽後更正紀錄。
- 除了 UI 禁用外，`openScoreModal()` 也加入程式邏輯防護，避免賽前透過其他方式開啟比分修改視窗。
