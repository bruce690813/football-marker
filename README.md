# 足球場邊記錄器 v6.137

直接基於 v6.136；僅新增摘要中的「分享／儲存兩張圖片（詳細版＋視覺精簡版）」功能，原有兩種單張輸出與主畫面儲存圖片均保留。

## 操作

比賽結束 → 摘要 → 點選「分享／儲存兩張圖片」。支援多檔案分享的瀏覽器會以同一次系統分享選單提供詳細版及 4:5 視覺精簡版兩個 PNG；單張選項仍可分別選擇。

若瀏覽器或分享目標不支援一次分享兩個檔案，摘要將顯示**兩個獨立下載連結**，需分別儲存。使用者取消系統分享時不會自動下載。某些第三方 App 可能自行限制多附件分享，需在 iPhone Safari／LINE 實機驗收。

## 版本差異

- 摘要加上雙圖片輸出按鈕，保留詳細版及視覺精簡版原本的單張按鈕。
- 同一點擊事件內同步產生兩張 Canvas PNG，傳入 `navigator.share({files: [詳細版, 精簡版]})`，並以 `navigator.canShare` 判斷支援情況。
- 不支援或分享失敗（非使用者取消）時顯示兩個下載連結。
- 不修改比分判定、既有 Canvas 繪圖、CSV、事件記錄、手機主畫面及桌面外框。

## 測試

已執行 HTML 中 JavaScript 語法、變更範圍及 ZIP 檔案檢查。iOS Safari 與 LINE 實機多圖分享仍須驗證；不得把靜態檢查視為端到端驗證。
