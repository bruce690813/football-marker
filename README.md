# 足球場邊記錄器 v4.24

此壓縮檔包含：

- `index.html`：足球場邊記錄器 v4.24 主程式
- `README.md`：本說明文件

## 使用方式

### 本機開啟
直接用瀏覽器開啟 `index.html` 即可使用。

### GitHub Pages
將 `index.html` 上傳到 GitHub Pages 專案根目錄，並確認檔名維持為 `index.html`。

## 版本
v4.24

## 本版重點
- 重新壓縮「本場事件」模組高度，避免 Safari 底部工具列持續遮住「紀錄」按鈕。
- 縮小主事件按鈕高度、黃紅牌列高度、紀錄列高度與區塊間距。
- 保留「主事件 → 黃紅牌 → 紀錄」的操作邏輯，但改成更緊湊的垂直節奏。
- 讓紀錄按鈕在 iPhone 畫面上更容易完整露出。
