# 足球場邊記錄器 v3.32

## 修正：開始比賽前必填欄位聚焦

- 我方、對手、場地在開始比賽前皆為必填。
- 按「開始比賽」時依序檢查：我方 → 對手 → 場地。
- 第一個未填欄位會自動聚焦。
- 我方／對手因為平常使用顯示文字而隱藏真正輸入框，本版會先切換成編輯狀態，再顯示游標與焦點框。
- 場地缺少時直接聚焦場地欄位。
- 不會一次跳多個欄位；使用者補完後再次按開始，再檢查下一個缺少欄位。


## v3.32 修正
- 賽前場地輸入完成後，重新檢查我方 / 對手 / 場地三個必填欄位。
- 若對手仍空白，會自動開啟對手輸入框並聚焦。
- 引導流程中的對手與場地也改為真正必填，不再允許空白直接跳過。
