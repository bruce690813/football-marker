# 足球精彩標記器 v2.17 — 手機單頁精簡版

## 這版調整
1. 手機畫面更緊湊
- 我方 / 對手 / 場地欄位濃縮
- 時間紀錄預設收合
- 主要功能集中，降低往下滑動距離

2. 時間只顯示到秒
- 主畫面計時
- 時間紀錄
- 比賽摘要
- 匯出圖片 / HTML
都改成秒，不再顯示毫秒

3. 圖片改為「儲存到手機」導向
- 按「儲存圖片」時，會優先呼叫手機分享面板
- 在 iPhone 可選擇「儲存影像 / 儲存到照片」
- 若裝置不支援，則會改開啟圖片新分頁，可長按圖片儲存

## 檔案說明
- index.html：GitHub Pages / 手機網頁版
- marker_clip_tool_v2_14.py：Mac 剪輯工具
- start_mac.command：Mac 雙擊啟動腳本

## 建議
若 iPhone 沒直接跳出「儲存影像」，可先按：
- 儲存圖片
- 分享面板
- 選擇「儲存到照片」或「儲存影像」
