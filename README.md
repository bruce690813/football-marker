# 足球場邊記錄器 v4.16

此壓縮檔包含：

- `index.html`：足球場邊記錄器 v4.16 主程式
- `README.md`：本說明文件

## 使用方式

### 本機開啟
直接用瀏覽器開啟 `index.html` 即可使用。

### GitHub Pages
將 `index.html` 上傳到 GitHub Pages 專案根目錄，並確認檔名維持為 `index.html`。

## 版本
v4.16

## 本版重點
- 修正比分區左右球隊名稱顯示邏輯，四字隊名優先維持單行顯示。
- 5～6 字隊名先自動縮字並維持單行，不再過早拆成兩列。
- 7 字以上的較長隊名才改為兩行顯示，兼顧可讀性與版面穩定。
- 延續 v4.15 的深色局部玻璃化與高對比操作區設計。
