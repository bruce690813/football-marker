# 足球場邊記錄器 v4.68

## 本版修正：中場事件紀錄與主卡間距

### 原因
v4.67 為了縮短中場畫面高度，曾將中場 `recordOnly` 模組設定為 `margin-top:-4px`。
在實際 iPhone Safari 畫面上，雖然內容沒有真正覆蓋，但兩張卡片的外框、陰影與圓角會視覺上黏在一起，看起來像重疊。

### v4.68
- 中場「主比分卡 → 事件紀錄」改為 **8px 明確間距**
- 移除負 margin
- 事件紀錄內部仍維持 compact，不增加多餘高度
- 賽前、比賽中、下半場、全場維持 v4.67 原設計，不做額外結構修改
