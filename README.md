# 足球場邊記錄器 v4.45

此壓縮檔包含：

- `index.html`：足球場邊記錄器 v4.45 主程式
- `README.md`：本說明文件

## 使用方式

### 本機開啟
直接用瀏覽器開啟 `index.html` 即可使用。

### GitHub Pages
將 `index.html` 上傳到 GitHub Pages 專案根目錄，並確認檔名維持為 `index.html`。

## 版本
v4.45

## 本版重點
- 強化全場狀態下的「本場事件統計」視覺層級。
- 四個統計卡直接對應事件色：
  - 進球：綠色
  - 射門：金黃色
  - 撲救：藍色
  - 防守：紫色
- 新增對應 icon，讓使用者除了比分外，也能更快掃到事件統計。
- 標題增加左側導引亮條，提升區塊辨識度。
- 數字字級放大，統計卡整體亮度與對比提高。
- 保持整體深色轉播風格，同時提高全場統計可讀性。
