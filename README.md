# 足球場邊記錄器 v4.29

此壓縮檔包含：

- `index.html`：足球場邊記錄器 v4.29 主程式
- `README.md`：本說明文件

## 使用方式

### 本機開啟
直接用瀏覽器開啟 `index.html` 即可使用。

### GitHub Pages
將 `index.html` 上傳到 GitHub Pages 專案根目錄，並確認檔名維持為 `index.html`。

## 版本
v4.29

## 本版重點
- 同一球隊、同一背號球員累積第二張黃牌時，第二張黃牌會自動轉為紅牌。
- 事件紀錄會顯示為「紅牌（兩黃）」，方便辨識是兩黃變紅而非直接紅牌。
- 兩黃變紅後，該球員立即套用紅牌退場規則，後續不能再記錄進球、射門、撲救、防守等球員事件。
- 若兩黃變紅的球員正好是目前守門員，會沿用 v4.28 流程跳出更換守門員視窗，使用者也可以選擇稍後設定。
- 事件編輯若造成同一球員累積第二張黃牌，也會自動轉為紅牌。

> 注意：系統需要有球員背號才能判斷是否為同一位球員；若黃牌紀錄略過背號，無法自動累計兩黃。
