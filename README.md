# 足球場邊記錄器 v6.158｜MVP 金色展示台與記憶球分離修正

版本日期：2026-10-31

## 修正範圍及原因
- **直接基底**：上一版 `football_marker_v6_157.zip`；正式原始設計基準仍為 `football_marker_v6_51.zip`，作廢的 v6.52／v6.53 未使用。
- **根本原因**：上一版 MVP Canvas 金色底板延伸至 Y=872，記憶球文字區塊 Y=867 開始，二者幾何上重疊；而 v6.156 的內嵌背景素材中也有一塊預先畫好的舊黃色底板，單改球衣尺寸無法消除重疊。
- **本次解法**：精簡版 MVP 台面調整為 X=258、Y=667、寬612、高151（底緣818）；與文字區塊 Y=867 之間留 49px，並降低底板陰影向下延伸。球衣重新排列在新台面內，限制陰影外溢，背號仍來自原有 MVP 資料。同步局部修正內嵌底圖的舊黃色台面，避免縮短 Canvas 台面後露出過長的舊底圖。
- **保留**：詳細版圖片、四項統計、比賽比分/事件、球衣配色、CSV、雙圖片分享、摘要、手機主畫面、各比賽階段和 PK 邏輯均未修改。

## 視覺驗收和測試
- ✅ v6.157 → v6.158 原始 HTML 差異驗證：版本標示、精簡版專用背景圖片與 `makeVisualSummaryCanvas()` 以外的程式內容逐字相同。
- ✅ Node.js `--check`：4 段內嵌 JavaScript 全部通過。
- ✅ Chromium 隔離呼叫**實際精簡版函式**，輸出 900×1125 PNG，已目視確認金色 MVP 底板停止於記憶球上方，不再露出舊金色底板的下緣；此測試使用模擬「忠義國小 4:1 A STAR」資料。
- ✅ 六種資料模擬可執行 PNG 輸出：我方勝利、平手、對手獲勝、八位並列 MVP、長隊名、藍色球衣（只證明隔離繪圖無 JavaScript 例外）。
- ✅ ZIP 只有 `index.html`、`README.md`、`SECURITY_CHECKLIST.md`，不包含 `.diff`。
- ⬜ iPhone Safari / LINE 真機雙圖分享、全部賽事階段、PK、不同尺寸手機之完整回歸**尚未執行**，不得宣稱通過。

> 交付 PNG 為隔離執行實際 Canvas 的輸出，不是 AI 概念示意。海報中的樂樂與進球情境屬美術插畫，不代表該場真實攝影。
