# 足球場邊記錄器 v3.53

## 本版更新

### 1. 本場球員名單改為點選優先
- 名單視窗新增「快速點選背號」。
- 常用背號以按鈕方式呈現，操作方式與進球選球員一致。
- 點一下加入本場名單，再點一次即可取消。
- 已選背號使用綠色高亮顯示。
- 原本手動輸入仍保留，作為其他背號備援。
- 名單設定後，進球、射門、防守、牌卡、助攻與 GK 仍優先使用本場名單。

### 2. 賽事名稱 / 場地資訊層級調整
- 賽事名稱維持第一列主要資訊，字級與高度略提高。
- 第二列改為約 56% 場地 + 44% 球員名單。
- 避免場地欄位視覺寬度明顯大於賽事名稱。
- 場地字色與字級略降低，維持次要資訊定位。

其他既有功能與資料格式維持不變。
