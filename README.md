# 足球場邊記錄器 v4.44

此壓縮檔包含：

- `index.html`：足球場邊記錄器 v4.44 主程式
- `README.md`：本說明文件

## 使用方式

### 本機開啟
直接用瀏覽器開啟 `index.html` 即可使用。

### GitHub Pages
將 `index.html` 上傳到 GitHub Pages 專案根目錄，並確認檔名維持為 `index.html`。

## 版本
v4.44

## 本版重點
- 統一黃／紅牌三步驟操作流程的 modal 視覺語言。
- 黃／紅牌選擇按鈕略縮高度，但仍保留大觸控區。
- 取消按鈕提高辨識度，不再看起來像 disabled。
- 選擇球隊頁使用輕微藍灰差異區分我方與對手，不使用勝負語意色。
- 球員步驟標題統一為「黃牌｜選擇球員 / 紅牌｜選擇球員」。
- 背號矩陣的圓角、邊框與陰影統一到球隊選擇頁的語言。
- 「其他背號 / 略過背號 / 取消這筆牌卡」重新拉開操作層級。
- 不改變兩黃變紅、紅牌退場、守門員紅牌更換等既有邏輯。
