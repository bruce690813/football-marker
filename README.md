# 足球場邊記錄器 v2.61

## 摘要圖片長隊名顯示修正
- 修正摘要預覽可完整顯示隊名，但儲存 / 分享圖片時隊名被壓縮或出現省略號的問題。
- 原因：摘要圖片是 Canvas 重新繪製，不是直接截取摘要 DOM；舊版 Canvas 左右隊名可用寬度較窄。
- 匯出圖片左右隊名卡由 246px 加寬至 286px。
- 中央比分框由 368px 縮為 302px，仍足以清楚顯示比分。
- 球隊名稱維持最多兩行，優先完整顯示；兩行仍放不下時才縮字，最後才省略。
- 比分仍固定置中，不會因長隊名位移。
- 預先處理字型量測，但不在 iPhone 分享按鈕點擊後加入 await，以免 Safari Web Share 失去 user activation。
