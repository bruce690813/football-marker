# 足球場邊記錄器 v6.133

## 開發基礎
以 v6.132 正式交付 ZIP 為直接基底；延續此前由正式 v6.51 衍生的既有功能與樣式。不使用已作廢的 v6.52、v6.53。

## 本次修改（僅限摘要／分享圖片）
1. 摘要：新增本場事件統計（進球我方／對手、射門、撲救、防守），安排在比賽基本資訊之後、時間紀錄之前，緊鄰比分與賽況區。
2. 分享圖片：新增精簡四欄統計，與摘要共用 `reportEventStatsData()`，放在比賽基本資料之後、時間紀錄與球員／事件資訊之前。
3. 摘要與分享圖片比分處新增「勝」圓章：完成比賽後，一般比賽依比分、PK 完成後依 PK 結果判定，平手無勝方章；僅標示勝方。
4. 版本號改為 v6.133。

## 原有功能
維持原有足球場邊記錄器的賽前、比賽中、中場、延長賽、PK、比賽結束、摘要、分享圖片、CSV 匯出與 YouTube 時間軸處理。未修改事件資料或 CSV 結構。主畫面統計和勝方章外觀不修改。

## 注意
分享圖片為 Canvas 自行繪製，本次新增精簡卡片而不調整智慧事件雙欄演算法。新增卡片會增加圖片高度。建議在 iPhone Safari、Mac Firefox 實際走完測試再對外部署。詳見 SECURITY_CHECKLIST.md。
