# 足球場邊記錄器 v6.152

## 基底與範圍
以正式 v6.51 為原始設計／功能基準的累加版本 **v6.151** 為直接修改基底。只改動「視覺精簡版」Canvas 函式及其內嵌背景、樂樂插畫素材；保留詳細版、雙圖分享、摘要、CSV 及主畫面。

## 修改紀錄
1. 移除標題、統計、MVP、記憶球周圍重複的厚重長方形卡框；改為浮動標題、曲線比分主視覺、玻璃波浪統計帶、金色弧面 MVP 舞台及無框敘事區。
2. 重繪進球／射門／撲救／防守圖示為相同尺寸的 Canvas 向量圖標，採一致垂直對齊坐標，不依賴不同 Emoji 的字型高度。
3. 精簡版球衣使用相同的既有球衣顏色「類別」，提高飽和度與立體高光（例：原本紅色仍是紅色，不會變更記錄器選項）。
4. 重新製作可離線使用的戶外球場背景，清理樂樂與金色記憶球插畫邊緣，改善色塊與裁切瑕疵。
5. 移除精簡版內文字提示「球內畫面為情境插畫，非本場實拍」；畫面仍為美術情境，**非本場真實比賽照片**，不得作為實際事件畫面證明。
6. 版本號更新為 v6.152。

## 交付與限制
- ZIP 包含 index.html、README.md、SECURITY_CHECKLIST.md；不包含開發用 diff。
- 金色記憶球內的足球攻門場景為插畫。
- 已使用隔離 Canvas 測試頁產生 PNG 作為視覺測試，不代表 iPhone Safari、LINE 雙圖分享或全賽程已完成實機測試。
