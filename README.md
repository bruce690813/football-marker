# 足球場邊記錄器 v4.85

## 本版修正：摘要「進球紀錄」助攻資訊被截斷

### 問題
原本「球員 / 隊伍」欄位把：
- 球隊
- 進球者背號
- 助攻者背號

全部塞在同一行，手機寬度不足時會被 `…` 截斷。

### v4.85 調整
- 球隊＋進球者背號：維持第一行。
- 助攻資訊：改為獨立第二行，以黃色次要資訊顯示。
- 進球紀錄列高度自動增加，避免文字互相擠壓。
- 比分欄仍固定在最右側，不影響掃讀。
- 儲存／分享的摘要圖片同步採用同樣邏輯，助攻資訊不再與球隊名稱擠在同一行。

### 視覺層級
1. 半場 / 時間
2. 進球序號
3. 球隊 + 進球者
4. 助攻
5. 比分
