# 足球場邊記錄器 v3.83

## 賽前資訊改為 2 × 2 矩陣

依照足球場邊實際操作順序，賽前上方調整為：

### 第一列
`🏆 黃蜂盃  ｜  🏟️ 新莊體育場`

- 賽事名稱與場地左右等寬
- 圖示固定顯示，不會因輸入文字後消失
- 保留足夠字級與觸控高度
- 長文字在輸入時仍可正常水平查看 / 編輯

### 第二列
`👥 名單 12人  ｜  🧤 守門員 #21`

順序改成：
1. 先確認本場球員名單
2. 再指定守門員

符合足球賽前準備流程。

### 中文說明
不只依賴 Emoji：

- `👥 名單 12人`
- `🧤 守門員 #21`

在戶外強光下仍可直接理解按鈕用途。

如果尚未設定守門員：

`🧤 守門員 未設定`

### 視覺層級
賽前仍維持：
- 比分 / 計時為主要比賽資訊
- `▶ 開始比賽` 為唯一 Primary Action
- 名單 / 守門員屬於次要準備資訊
- 不會放大到搶過比分區

### 其他狀態
本版只調整「賽前」排列。

比賽中仍可維持較適合即時操作的快捷順序，
全場後的 `＋ 新比賽` 也維持 v3.82 邏輯。

其他功能維持 v3.82 不變。
