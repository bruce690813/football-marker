# 足球場邊記錄器 v4.61

## 本版重點：本場球員名單 UI/UX 重整

### 1. 移除重複的「已選本場名單」
快捷背號本身就是名單狀態：
- 灰白：未選
- 綠色：已選
- 再點綠色一次：取消

不再把同一批背號完整重複列在下方。

### 2. Progressive Disclosure
只有「不在快捷列表中的特殊背號」才會出現「其他已選」Chip。
一般情況不占任何版面高度。

### 3. 明確提示
標題下方固定提示：
「點一下加入，再點一次取消」

### 4. 即時人數
右上角人數即時更新，新增 / 移除時會有非常輕微的縮放回饋。

### 5. 單人取消可復原
取消球員後顯示：
「已移除 #36　復原」
不需要每次跳確認視窗。

### 6. 清空名單
清空改為低調危險操作，只有清除全部時才確認：
「確定清空目前 11 位球員嗎？」

### 7. 完成按鈕固定
名單內容可以捲動，但「完成」固定在 Modal 底部，降低 iPhone Safari 底部工具列干擾。

### 8. 沿用上一場名單
若存在上一場名單，會顯示：
「↻ 沿用上一場名單 11 人」
可快速帶入下一場。

### 9. 其他背號
- 已存在：提示「已在本場名單中」
- 1～99 以外：提示格式錯誤
- 已紅牌退場：禁止重新加入本場名單

### 10. 上一場名單語意修正
不再於本場每次編輯時覆寫「上一場名單」；
上一場資料在全場結束 / 建立新比賽時才保存。
