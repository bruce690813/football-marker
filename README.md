# 足球場邊記錄器 v6.145

## 開發來源
由正式 v6.51 系列延伸，直接以上一版 v6.144 ZIP 為修改基底；v6.52、v6.53 不作為開發基底。

## v6.145 修改
- **僅調整視覺精簡版 Canvas**：改為上方轉播式藍色比分牌、中間四項原有事件統計、下方球衣背號 MVP 與戶外綠茵球場／球門／足球。
- 保留比賽名稱、日期、場次、雙方隊名、全場比分、勝方標示及球衣配色同步。
- 四項事件：進球（雙方比分）、射門／撲救／防守（依既有統計），未虛構角球、射正、控球率等資料。
- 未修改完整詳細版分享圖片、單一「分享/儲存圖片」按鈕、雙圖分享與備援、CSV 或記錄器操作流程。

## 測試及限制
- 比對 v6.144→v6.145：主要修改為視覺精簡版 Canvas 主繪製內容與版本標示。
- 4 個 JavaScript 區塊均經 Node.js `--check` 語法檢查。
- Chromium 實際 PNG 渲染於本環境逾時，**未通過實際圖片驗收**，請於 Safari／Firefox 使用實際比賽資料確認。
- 因圖形使用 Canvas 原生繪製，與概念海報的寫實 3D 材質不同；不應將美術示意視為程式截圖。
