# 足球場邊記錄器 v2.18 — 手機單頁版

這版再進一步精簡手機主畫面：

- 移除「CSV 給剪輯程式使用｜資料會自動儲存｜圖片可存到照片」
- 移除「資料會自動儲存在此手機」
- 移除「下載 CSV」
- 保留「分享 CSV」，可直接透過 iPhone 分享面板 AirDrop 到 Mac 或存到檔案
- 最後操作區濃縮成一排：
  - 📋 摘要
  - 🖼 儲存圖片
  - 分享 CSV
- 再縮短卡片、計時區與事件按鈕的垂直高度，盡量讓手機一頁就能看到主要功能

建議用途：
- 摘要：手機直接查看本場紀錄
- 儲存圖片：分享到照片 / 家長群 / LINE
- 分享 CSV：AirDrop 到 Mac 給剪輯程式讀取


## v2.18 修正
- 僅修正 iPhone / Safari 底部工具列遮住最後一排按鈕的問題。
- 功能完全沿用 v2.16；沒有重新加入 HTML、下載 CSV、JSON、手動儲存等已移除功能。


## v2.18 新增
- 我方隊伍名稱改為開始比賽前必填。
- 未填時不啟動計時，提示「請先輸入我方隊伍名稱」，並自動聚焦與紅框提示。
- 自動記住最近一次有效的我方隊伍名稱。
- 新比賽保留我方名稱，清空對手、場地、比分、時間與事件。
- 新比賽後游標自動移至對手欄位。
