# ⚽ 足球場邊記錄器 v5.80

本版依照「摘要 / 儲存圖片功能重疊」的 UI/UX 討論調整。

## v5.80 調整內容

1. **主畫面移除「🖼️ 儲存圖片」**
   - 主畫面只保留 `📋 摘要` 與 `📄 匯出 CSV`。
   - `＋ 新比賽` 維持下一列整排寬度。

2. **摘要頁保留唯一的圖片輸出入口**
   - 摘要底部只保留 `分享 / 儲存圖片`。
   - 使用 iPhone 時會叫出系統分享選單，可分享或選擇「儲存影像」。

3. **「關閉」改成摘要右上角 ×**
   - 移除原本底部佔一大格的「關閉」按鈕。
   - 右上角 × 保留足夠觸控範圍，也沿用既有摘要焦點 / 無障礙流程。

4. **快速使用指南同步更新**
   - 改成「摘要 → 分享 / 儲存圖片」的操作流程，避免與主畫面產生重複概念。

## 操作邏輯

- `摘要`：查看比賽成果
- `分享 / 儲存圖片`：輸出摘要成果
- `匯出 CSV`：匯出原始事件資料

## 使用方式

將 ZIP 解壓後，把 `index.html` 放到原本 GitHub Pages 專案根目錄即可。

若網址仍是同一個 `https://bruce690813.github.io/football-marker/`，
瀏覽器的同源 localStorage 不會因為這次 UI 調整而改變。

## 版本基底說明

此交付版以你 GitHub 上的 **v5.79** 為固定基底，鎖定 commit：

`ff440dad7811b0c1b69a493ec0dff9c23ee012e6`

為避免把 80 多萬位元組的單檔程式人工重組造成遺漏，這個 `index.html`
會在載入時取得上述**固定 commit** 的 v5.79，再於瀏覽器中套用 v5.80 UI 調整。

- 不是抓「最新版」，所以日後 main 分支更新不會讓本包內容突然改變。
- 第一來源：GitHub Raw
- 備援來源：jsDelivr（同一固定 commit）
- 不會傳送比賽內容、名單或事件資料到外部。
- **因此第一次開啟需要網路連線。**

如果之後要製作「完全離線、單一 HTML 已全部合併」版本，
可直接以 v5.79 完整 ZIP / index.html 為基底再合併。
