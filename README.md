# 足球場邊記錄器 v4.71

## 修正：全場畫面不再自動往下捲

### v4.70 問題原因
v4.70 為了讓 `＋ 新比賽` 立即避開 iPhone Safari 底部工具列，
加入了進入全場後的自動 `scrollBy()` 校正。

結果是：
- `＋ 新比賽` 的確被抬高
- 但整個頁面 viewport 也一起往下捲
- 因此最上方「足球場邊記錄器」、賽事名稱、場地被推到畫面上方而看不到

### v4.71 修正方式
1. **完全移除全場自動捲動**
   - 不再使用 scrollBy / scrollTo 將頁面自行往下移。
   - 進入全場時保留使用者原本的 viewport 位置。

2. **保留 Safari 底部 Safe Area**
   - 防遮蔽改成只靠頁面最底下真實存在的文件流空間。
   - 使用者滑到最底時，`＋ 新比賽` 可以完整拉到 Safari 工具列上方。

3. **加大 iPhone 尾端安全空間**
   - ≤430px：至少 220px
   - ≤390px：至少 232px
   - ≤375px：至少 244px

4. **不影響其他狀態**
   - 賽前 / 比賽中 / 中場 / 下半場 UI 與操作不變。

## 正確行為
- 一進入「全場」：畫面不自行跳動，最上方資訊仍維持原位置。
- 想按 `＋ 新比賽`：正常向下滑到最底即可。
- 滑到最底：按鈕可完整露出，不應再被 Safari 底欄截住。
