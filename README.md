# 足球場邊記錄器 v3.88

## 本版整合

v3.88 同時納入原本 v3.87 的 UI / 比分修正調整，
再加入「最近場地選擇」與名單圖示優化。

## 1. 賽前四格完全一致

四格：

- 🏆 賽事名稱
- 🏟️ 場地
- 👕 名單
- 🧤 守門員

統一：

- 卡片高度
- 左側 padding
- 固定 icon box
- 圖示視覺尺寸
- 圖示與文字間距
- 文字起始位置
- 文字 18px / 900
- placeholder 不縮小，只降低顏色

Emoji 本身視覺面積不同，因此做少量 optical correction，
目標是肉眼看起來一致，而不是只讓 font-size 數值相同。

## 2. 名單圖示改成 👕

原本 👥 在 iPhone 上偏灰藍，
與深藍按鈕背景太接近。

改成：

`👕 名單 0人`

更符合本工具實際上是「選本場球衣背號」的操作，
戶外辨識度也較高。

相關本場名單 / PK 選背號 / 摘要中的名單圖示同步使用 👕。

## 3. 場地：最近使用下拉 + 手動輸入

場地欄右側新增低調 `⌄`。

點擊後顯示：
- 最近使用場地
- 最多 8 筆
- 最近使用優先
- 自動去除重複場地
- `✎ 手動輸入其他場地`

原本的場地 input 完整保留，
使用者仍可直接手動輸入。

新場地在完成輸入、開始比賽或賽後儲存後，
會加入最近使用清單。

## 4. 修正比分顯示規則

顯示：
- 中場
- 等待延長賽
- 全場

隱藏：
- 賽前
- 比賽進行中
- 下半場進行中
- 延長賽進行中
- PK 進行中

比賽進行中由「進球事件」維護比分，
避免人工比分與事件紀錄 / CSV / 球員統計不同步。

## 5. 延續 v3.86

- 全場賽後工具列使用正常文件流，不遮蔽紀錄
- 移除「套用上場名單」
- 黃牌 / 紅牌為直向長方形
- 賽前重設會清空本場資料，只保留常用我方隊名
