# 足球場邊記錄器 v4.79

## 事件紀錄 UIUX 優化

### 事件紀錄改為 Timeline/Event Log
完整事件紀錄的閱讀順序調整為：
1. 半場 / 時間
2. 事件 icon + 球員背號 + 事件名稱
3. 球隊
4. 比分
5. 編輯 / 刪除

### 本版調整
- 球隊名稱固定單行顯示，避免「忠義國小足球 / 隊」破碎換行。
- 過長球隊名稱使用省略號，不任意斷字。
- 恢復事件 icon：
  - ⚽ 進球
  - 🥅 射門
  - 🧤 撲救
  - 🛡️ 防守
  - 🟨 黃牌
  - 🟥 紅牌
- 每種事件只使用左側細 accent，不把整列染色。
- 「第 N 筆」降低視覺權重。
- 時間與事件成為主要視覺焦點。
- 編輯 / 刪除按鈕縮小並降低彩度，但仍維持一鍵操作。
- 比分固定置於右上方，掃讀更一致。
- 本場事件統計的 drill-down 細節仍維持唯讀，不受本次改版影響。
