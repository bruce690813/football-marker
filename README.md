# 足球場邊記錄器 v4.49

此壓縮檔包含：

- `index.html`：足球場邊記錄器 v4.49 主程式
- `README.md`：本說明文件

## 使用方式

### 本機開啟
直接用瀏覽器開啟 `index.html` 即可使用。

### GitHub Pages
將 `index.html` 上傳到 GitHub Pages 專案根目錄，並確認檔名維持為 `index.html`。

## 版本
v4.49

## 本版重點
- 將賽事名稱 / 場地資訊列的字級在各比賽狀態完整統一。
- 套用狀態：
  - 上半場 / 比賽進行中
  - 中場
  - 下半場
  - 等待延長賽
  - 延長賽進行中
  - PK / 比賽中斷狀態
  - 全場
- 一般 iPhone 統一約 15.5～16.2px。
- 小型 iPhone 統一為 15px。
- 資訊列高度統一約 34～36px。
- 全場狀態的 resultMetaText 也同步套用相同字級，避免舊 CSS 規則將文字縮小。
- 不改變任何比賽流程、比分、事件、牌卡、摘要或匯出功能邏輯。
