# 足球場邊記錄器 v3.12

## 本版調整

### 1. 黃牌 / 紅牌按鈕視覺
- 主按鈕改為深靛藍／藍灰色漸層。
- 避免使用黃色或紅色整顆底色，防止與 🟨 / 🟥 牌卡本身混在一起。
- 增加藍色邊框與輕微陰影，降低「灰色＝不可按」的錯覺。
- 黃牌、紅牌圖示仍維持最高辨識度。

### 2. PK 球員背號驗證
- PK 背號與一般進球背號採相同規則：`1～99`。
- 輸入欄位最多只允許 2 位數。
- 非數字會自動過濾。
- `0` 或其他不合法值不會寫入紀錄。
- 我方有效 PK 背號仍可加入常用背號。

### 3. PK 摘要顯示球員背號
- 網頁摘要新增 PK 欄位標題與每輪背號。
- 顯示格式例如：`#7 ✓`、`#10 ×`。
- 未填背號則顯示 `—`。
- PNG 分享圖片及 HTML 報告也同步加入每輪 PK 球員背號與結果。

### 4. LIVE 狀態文字置中
- 「比賽中 / 下半場 / 延長賽」改為以整個狀態膠囊的正中央定位。
- 左側 LIVE 與右側時間維持原位置，不再把中央狀態文字視覺上往左推。

其他既有功能維持不變。
