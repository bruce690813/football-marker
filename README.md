# 足球場邊記錄器 v4.32

此壓縮檔包含：

- `index.html`：足球場邊記錄器 v4.32 主程式
- `README.md`：本說明文件

## 使用方式

### 本機開啟
直接用瀏覽器開啟 `index.html` 即可使用。

### GitHub Pages
將 `index.html` 上傳到 GitHub Pages 專案根目錄，並確認檔名維持為 `index.html`。

## 版本
v4.32

## 本版重點
- 修正賽前「最近使用場地」下拉選單被後方名單／守門員／比分區遮住的問題。
- 場地下拉選單改成 viewport 固定浮層，使用較高層級顯示，不再受主卡片內部排版堆疊影響。
- 下拉選單會依 iPhone 可視範圍自動定位；若下方空間不足，會自動改為向上展開。
- Safari 捲動、網址列高度變化或旋轉畫面時，選單會重新定位。
- 延續 v4.31 既有功能與版面。
