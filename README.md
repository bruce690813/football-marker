# 足球場邊記錄器 v3.95

## 1. 修正重新整理後 Auto-fit 沒有自動執行

v3.93 / v3.94 的長文字縮放邏輯本身正確，
但 Safari 重新整理或 LocalStorage 還原資料後，
`render()` 沒有固定呼叫 Auto-fit。

v3.95 將：

`updateAllPreMetaFits()`

正式納入每次 `render()` 的標準流程。

因此以下情境都會立即重新判斷：
- Safari 重新整理
- 關閉頁面後重新開啟
- LocalStorage 還原比賽資料
- 程式重新 render
- 新比賽載入資料

賽事名稱與場地都會套用既有縮字規則。

## 2. 全場直接顯示實際比賽時間

全場狀態列由：

`全場`

改為：

`全場 40:37`

讓賽後不用展開任何區塊，
就能直接知道本場真正的比賽時間。

如果有 PK，原本 PK 狀態文字仍保留。

## 3. 時間紀錄：全場才補回「實際比賽時間」

比賽進行中：
- 不顯示，因上方 LIVE 已有經過時間

中場：
- 不顯示，上方已有中場休息時間

全場：
- 顯示 `實際比賽時間`
- 使用 `state.finalElapsed`

例如：

`實際比賽時間`
`40:37`

這不是用：

`結束時間 - 開始時間`

計算，因此不會把：
- 中場休息
- 等待下半場
- 等待延長賽

算進真正的比賽時間。
