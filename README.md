# 足球場邊記錄器 v4.41

此壓縮檔包含：

- `index.html`：足球場邊記錄器 v4.41 主程式
- `README.md`：本說明文件

## 使用方式

### 本機開啟
直接用瀏覽器開啟 `index.html` 即可使用。

### GitHub Pages
將 `index.html` 上傳到 GitHub Pages 專案根目錄，並確認檔名維持為 `index.html`。

## 版本
v4.41

## 本版重點
- 全場狀態維持「統計在上、明細在下」的資訊順序。
- 「本場標記事件」改名為「本場事件統計」。
- 「本場事件」改名為「事件紀錄」。
- 讓全場畫面的資訊層級更清楚：最終比分 → 本場事件統計 → 事件紀錄 → 摘要／儲存圖片／匯出 CSV → 新比賽。
- 事件紀錄彈窗與比賽摘要標題同步使用一致命名。
