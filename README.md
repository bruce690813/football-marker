# 足球場邊記錄器 v2.98

本版修正與 UI/UX 調整：

1. 編輯事件紀錄的球員背號
- 修正 iPhone 鍵盤開啟後，儲存按鈕被擠到畫面外、造成「背號無法修改」的操作問題。
- 編輯視窗改成：
  - 固定標題區
  - 中間內容可捲動
  - 底部「取消 / 儲存修改」固定可見
- 背號輸入框放大、加強藍色 focus 狀態。
- 鍵盤按「完成」可直接收起鍵盤。
- 背號仍限制 1–99，並可留空。

2. 本場事件紀錄欄位順序
- 改成：第幾筆 → 時間 → 事件 / 球員 / 比分 → 編輯 → 刪除。
- 時間改為黃色粗體並置中，方便快速對影片時間點。
- 重新分配欄寬，使手機版每列視覺更平均。
