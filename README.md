# 足球場邊記錄器 v6.140

## 開發基底
以正式 v6.51 為原始設計基準；本次只從累加版本 v6.139 更新視覺精簡版，不採用作廢的 v6.52／v6.53。

## 本次修改
- 僅於 `makeVisualSummaryCanvas()` 增加離線 Canvas 球場聚光燈、少量勝利紙花與比分金色線條，增強海報式主視覺。
- 將 MVP 以金色描邊、深綠漸層做成獨立表揚區；球員仍以球衣背號呈現。
- 球衣繼續共用 `currentJerseyPalette()`；對手未設定球衣時維持中性灰。
- 不修改詳細版圖片、雙圖/單圖分享功能、事件、CSV、比分邏輯與手機版 UI。

## 注意
- 海報視覺為原生 Canvas 圖形，不包含寫實球場照片；先前影像生成的圖片僅作風格參考。
- 功能性回歸及 iPhone Safari、LINE 多圖分享需實機驗證。
