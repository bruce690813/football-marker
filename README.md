# 足球場邊記錄器 v4.83

## 比分分隔符 Design System

### 即時主比分牌：維持冒號 `:`
主畫面的左右比分是獨立數字框，因此冒號最像電子記分板，也最符合目前 LIVE UI 的視覺語言。

- 例：`1 : 0`
- 冒號視覺權重稍微降低，不與黃色比分搶焦點。

### 文字化比分：統一使用 en dash `–`
以下偏「閱讀 / 回顧」的介面改用橫向比分格式：

- 摘要主比分：`1–0`
- 摘要圖片：`1–0`
- 各半場摘要：`1–0`
- 事件紀錄進球得分變化：`0–0 → 1–0`
- 事件紀錄中的文字比分
- PK 摘要比分
- 分享 CSV 時的分享面板文字
- HTML 摘要

### CSV 相容性
CSV 內部資料欄位 `score_after` **維持原本 `1:0` 格式**，不改成 `1–0`。
原因是 CSV 可能會被後續 Mac 剪輯或其他程式解析；這次只調整「人看的 UI」，避免破壞既有資料格式相容性。
