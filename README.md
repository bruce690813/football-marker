# 足球場邊記錄器 v3.59

## 新增：全場後「本場結果摘要卡」

只在全場結束後顯示，位置在主比分區塊下方、紀錄上方。

### 顯示內容
- 雙方隊名
- 最終正規比分
- 若有 PK：額外顯示 PK 比分
- 四項核心標記事件統計：
  - 進球
  - 射門
  - 撲救
  - 防守

### 設計原則
- 卡片維持約 100～130px 的精簡高度。
- 比分為最高視覺層級。
- PK 僅在實際有點球大戰時顯示。
- 統計只保留四項核心事件，不塞入牌卡、助攻等次要資訊。
- 賽前 / 比賽中 / 中場 / PK 進行中都不顯示。
- 完整內容仍由「摘要」負責，本卡只提供一眼掌握結果的功能。

其他 Match State UI 與既有功能維持不變。
