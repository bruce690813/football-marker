# 足球場邊記錄器 v4.47

此壓縮檔包含：

- `index.html`：足球場邊記錄器 v4.47 主程式
- `README.md`：本說明文件

## 使用方式

### 本機開啟
直接用瀏覽器開啟 `index.html` 即可使用。

### GitHub Pages
將 `index.html` 上傳到 GitHub Pages 專案根目錄，並確認檔名維持為 `index.html`。

## 版本
v4.47

## 本版重點
- 移除事件區上方獨立的「事件紀錄」標題。
- 原本「紀錄」按鈕改名為「事件紀錄」。
- 將區塊名稱與操作入口合併，減少重複資訊。
- 比賽進行中可省下一列高度，讓主事件、黃紅牌與事件紀錄更緊湊。
- 中場／全場 record-only 狀態同步移除多餘分隔線與上方空白。
- 右側「0 筆 / X 筆」數量顯示維持不變。
- 不改變任何事件記錄、牌卡、比分、摘要或匯出功能邏輯。
