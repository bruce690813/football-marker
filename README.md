# 足球場邊記錄器 v4.34

此壓縮檔包含：

- `index.html`：足球場邊記錄器 v4.34 主程式
- `README.md`：本說明文件

## 使用方式

### 本機開啟
直接用瀏覽器開啟 `index.html` 即可使用。

### GitHub Pages
將 `index.html` 上傳到 GitHub Pages 專案根目錄，並確認檔名維持為 `index.html`。

## 版本
v4.34

## 本版重點
- 賽前狀態下，「時間紀錄」預設只顯示標題與「展開」按鈕。
- 賽前不再顯示沒有資訊價值的「開始時間 --:--:-- / 結束時間 --:--:--」。
- 使用者按「展開」後，仍可查看開始／結束時間欄位與規定時間等完整設定。
- 全場結束後仍會在收合狀態直接顯示實際開始時間與結束時間。
