# 足球場邊記錄器 v3.74

## 本版重點：比賽中次要資訊放大

本版只調整 Live 比賽中的資訊可讀性。

### 賽事名稱 / 場地
原本 Live 專注模式會把賽事名稱與場地壓縮成一條資訊列，
但字級偏小。

v3.74：
- 字級放大
- 字重提高
- 文字顏色提高亮度
- 資訊列高度只小幅增加
- 維持單行省空間

設計原則：
仍然低於「LIVE / 比賽時間 / 中央比分」的視覺權重。

### GK / 球員人數
比賽中的：
- `🧤 #21`
- `👥 12人`

同步放大一級：
- 按鈕字級提高
- 圖示略放大
- 按鈕高度只增加少量

不使用比分等級的大字，避免搶過中央比分區。

### 小尺寸 iPhone
390px 以下另有縮放規則：
- 賽事 / 場地略縮
- GK / 人數略縮
- 避免把事件操作區往下推太多

## 其他功能
維持 v3.73 不變。
