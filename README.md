# 足球場邊記錄器 v4.48

此壓縮檔包含：

- `index.html`：足球場邊記錄器 v4.48 主程式
- `README.md`：本說明文件

## 使用方式

### 本機開啟
直接用瀏覽器開啟 `index.html` 即可使用。

### GitHub Pages
將 `index.html` 上傳到 GitHub Pages 專案根目錄，並確認檔名維持為 `index.html`。

## 版本
v4.48

## 本版重點
- 比賽中「賽事名稱 / 場地」字級由原本約 13～14.5px 提升到約 15.5～16.2px。
- 小型 iPhone 維持約 15px，降低長賽事名稱被截斷的機率。
- 資訊列高度同步提高到約 34～36px，避免只放大文字造成擁擠。
- 與守門員 / 名單約 15～16.5px 的字級更接近，視覺層級更平衡。
- 仍保持比分 / 計時為最高視覺優先層級。
- 不改變任何比賽、事件、牌卡、比分、摘要或匯出功能邏輯。
