## 本版重點
- 全場結束後，「時間紀錄」預設收合，只保留標題與「展開」。
- 開始時間、結束時間與完整時間明細仍可按「展開」查看，不刪除資料。
- 全場結束時會自動把時間紀錄收回，避免先前展開狀態持續佔空間。
- iPhone Safari 全場頁新增底部安全捲動空間，讓「摘要 / 儲存圖片 / 匯出 CSV / ＋ 新比賽」可以完整捲到瀏覽器工具列上方。
- 已以 393×852 手機 viewport 測試全場結果頁，並模擬 100px 底部瀏覽器遮罩檢查「＋ 新比賽」可完整露出。
