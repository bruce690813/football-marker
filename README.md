# 足球場邊記錄器 v3.82

## 本版重點：賽前移除「＋ 新比賽」

賽前本身就已經是新比賽的準備狀態，因此再顯示大型
`＋ 新比賽` 會產生重複語意與操作疑問。

v3.82 將比賽生命週期進一步整理。

### 賽前
主畫面改為：

- 🏆 賽事名稱
- 🏟️ 場地
- 🧤 GK ｜ 👥 本場球員名單
- 比分 / 時間
- `▶ 開始比賽`

`▶ 開始比賽` 是賽前唯一 Primary Action。

### GK / 球員名單
原本右上角的：

`GK ｜ ＋新比賽`

改成：

`GK ｜ 本場球員人數`

兩者都是賽前準備資料，視覺層級更一致。

### 重新設定
若賽前已經有實際設定進度，才會出現低權重：

`↺ 重新設定`

例如已設定：
- 對手
- 賽事名稱
- GK
- 本場球員名單
- 規定時間
- 與記憶值不同的場地 / 我方名稱

按下後會確認，再將賽前資料回復到基準狀態。

常用我方名稱與記憶場地仍保留，
避免每一場都重新輸入。

### 新比賽
正式的：

`＋ 新比賽`

只保留在「全場結束後」，
作為完成摘要 / 圖片 / CSV 後進入下一場的入口。

## 狀態設計
- 賽前：不顯示 ＋新比賽
- 比賽中：不顯示
- 中場：不顯示
- 等待延長賽：不顯示
- 延長賽 / PK：不顯示
- 全場：顯示 ＋新比賽

其他功能維持 v3.81 不變。
