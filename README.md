# 足球場邊記錄器 v3.08

## 新增：延長賽與 PK 點球大戰
- 下半場結束且比分平手時，可選「全場結束 / 延長賽 / PK 點球」。
- 延長賽可輸入 1～45 分鐘，並以獨立段落計時。
- 延長賽結束若仍平手，可選擇 PK 點球。
- PK 預設雙方各 5 點，每一點可輸入球員背號（選填）。
- 每一點可切換：待定 / 進球 / 未進。
- 5 輪後仍平手可「＋ 加一輪」繼續驟死賽。
- PK 比數獨立於正式比數，不會把 PK 進球加進比賽比分。
- 比賽摘要會顯示 PK 比數與每一輪結果。
- CSV 匯出會額外包含 PK 點球紀錄。
- 延長賽 / PK 狀態會保存於 LocalStorage，可中途關閉視窗後再繼續。
