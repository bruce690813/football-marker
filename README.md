# 足球場邊記錄器 v4.95

## 本版重點：我方球隊名稱不再阻擋開始比賽

### 實務情境
場邊最重要的是裁判吹哨後能立刻開始計時。

如果這時才跳出「請輸入我方球隊名稱」，使用者還要臨時輸入文字，
會造成操作不順，也可能讓比賽開始時間產生誤差。

## v4.93 採用方案 B

### 1. 我方球隊名稱改為「可稍後補充」
即使沒有輸入我方球隊名稱：

- `▶ 開始比賽` 仍可直接按
- 比賽立即開始計時
- 不跳阻斷式 Modal
- 不要求先輸入文字

### 2. 空白時先顯示「我方」
畫面與後續事件會先使用：

`我方`

作為暫代名稱。

之後可直接點「我方」補上正式球隊名稱。

### 3. 非阻斷提示
若空白隊名直接開賽，畫面會短暫顯示：

- `⏱ 已開始計時`
- `我方球隊名稱可稍後點「我方」補充`

提示不會擋住計時，也不需要按確認。

### 4. 常用隊名記憶保護
空白開賽時不會把空白寫進「最近使用的我方隊名」。

若使用者之前有常用球隊名稱，仍會保留供下一場使用。

### 5. 重新整理也不會偷偷改掉本場隊名
如果本場是用空白名稱開賽：

- 重新整理頁面後仍維持本場「我方」暫代狀態
- 不會被之前記憶的球隊名稱覆蓋

### 6. 其他欄位
下列資料本來就可以稍後補，本版維持：

- 對手
- 賽事名稱
- 場地

## UX 原則

優先順序改為：

**裁判哨音 → 立即開始計時 → 事件記錄 → 有空再補資料**

這比「資料填完整才能開始」更符合真正球場上的使用情境。

## v4.94 UI/UX：賽前與開賽後上方資訊順序一致化

### 調整前
賽前第二列：
- 左：👕 名單
- 右：🧤 守門員

開賽後第二列：
- 左：🧤 守門員
- 右：👕 人數

左右位置在開賽瞬間交換，會破壞使用者的視覺記憶與操作肌肉記憶。

### v4.94
賽前、比賽中、中場、下半場、延長賽統一為：

- 第一層：賽事 / 場地
- 第二層左側：`👕 名單 12人`
- 第二層右側：`🧤 守門員 #21`

開賽後仍保留較精簡的「🏆 賽事 · 🏟️ 場地」橫條，
避免增加垂直高度；但第二列的位置與語意完全和賽前一致。

### UX 效益
- 左右位置不再跳動
- 名單與守門員形成固定肌肉記憶
- 場邊快速查看 / 修改時更直覺
- 不增加比賽中畫面高度


## v4.95 UI/UX：PK Header 與整場 Match Flow 統一

### 調整前
PK 狀態會重新顯示大型表單型欄位：

- `🏆 賽事名稱`
- `🏟️ 場地 ▼`

因此從「比賽中 / 中場 / 延長賽」進入 PK 時，
視覺上會像切換到另一個設定頁面。

### v4.95
PK 狀態改成沿用整場比賽的 compact Header：

`🏆 黃蜂盃 · 🏟️ 新北高中`

下面維持：

`PK 點球`

接著才是：

- 正規賽比分
- `PK 0 : 0`
- `⚽ 記錄 PK`

### UI/UX 原則
- PK 是同一場比賽的決勝階段，不是新的設定頁。
- 賽事 / 場地資訊維持與比賽中、中場、延長賽相同的位置與視覺語言。
- 紫色只用來表達「PK 點球」特殊狀態，不讓整個 Header 都變成另一套介面。
- PK 不額外顯示名單 / 守門員快捷列，避免分散記錄點球的注意力。
