# 足球場邊記錄器 v6.151

以 v6.148 為基底，僅重新設計第二張「視覺精簡版」分享海報。

## 修改紀錄
- 以 4:5 圖二視覺規格為基準，整合較有層次的戶外球場氣氛、立體金色比分、玻璃統計帶、MVP 金色榮耀台。
- 加入高品質中性戶外球場／金色玻璃記憶球視覺素材，內嵌於單一 HTML。球體內景是意象，**不是當場真實照片**。
- 賽事名稱、日期、比分、勝負、球衣色、統計及 MVP 仍動態讀取；不使用假比分或虛構事件。
- 詳細版圖片、同時分享兩張、CSV、主畫面均保留。

## 已知限制
- 概念圖內的真人、寫實球衣和記憶球光線尚不能逐像素重現；本版使用內嵌素材與 Canvas 合成。
- iPhone Safari/LINE 實機雙圖分享及全賽程回歸仍需驗證。
