# 足球場邊記錄器 v4.86

## 本版修正：摘要時間資訊去重

### 問題
全場摘要中，同一個總比賽時間同時出現在：
1. 比分區下方，例如 `⏱ 3小時 49分 48秒`
2. 「時間紀錄」區的大字總時間
3. 長時間時另外再顯示 `總計 229:48`

造成資訊重複，視覺焦點也不夠集中。

### v4.86 調整
- 移除比分區下方的總時間。
- 「時間紀錄」區保留唯一主要總時間。
- 移除 `總計 229:48` 這類第二種格式的重複顯示。
- 摘要上方只保留：
  - 場地
  - 本場球員名單
- 分享 / 儲存圖片中的「實際比賽時間」仍保留一份，但移除括號中的重複總計。
- HTML 匯出摘要同步採用相同資訊層級。

### 最終資訊分工
- 比分摘要：比分、場地、本場球員
- 時間紀錄：開始、結束、總時間、中場資訊
- 事件內容：進球紀錄、其他精彩事件
