# 足球場邊記錄器 v3.11

## 本版調整：長時間與跨日比賽的時間可讀性

### 1. 超過一小時的總時間
- 未滿 1 小時：維持 `MM:SS`，例如 `43:17`。
- 1 小時以上：主顯示改為 `X小時 X分 X秒`，例如 `7小時 23分 17秒`。
- 摘要畫面同時以次要小字保留原始累計分鐘格式，例如 `總計 443:17`，方便核對。

### 2. 跨日比賽
- 若開始與結束為同一天：仍只顯示時間，例如 `23:19:29`。
- 若開始與結束跨不同日期：自動補上月／日，例如：
  - 開始：`08/24 23:19:29`
  - 結束：`08/25 06:42:46`
- 摘要畫面會額外顯示「跨日」標籤。
- 同一天不顯示「跨日」，避免增加不必要資訊。

### 3. 同步範圍
- 網頁比賽摘要
- PNG 分享／儲存圖片
- HTML 報告

既有比賽流程、牌卡、延長賽、PK、事件紀錄與 CSV 功能維持不變。
